## Что такое Aither?

**Aither** — это внутренняя платформа для работы с AI-моделями (LLM). Она предоставляет доступ к большим языковым моделям через **Web UI** (основной способ) и стандартный API, совместимый с OpenAI.

Проще говоря: вы общаетесь с AI-моделью в браузере или через API. Вы можете:
- Вести диалог с моделью в браузере (**Web UI — основной интерфейс**)
- Генерировать текст (completion)
- Использовать разные модели для разных задач
- Создавать API-ключи для автоматизации и AI-агентов

---

## Зачем проводится Closed Beta?

Перед тем как открыть доступ для всех, мы проводим **закрытое тестирование** с ограниченной группой пользователей (до 5 человек).

**Цели тестирования:**
1. Проверить стабильность системы под реальной нагрузкой
2. Протестировать Web UI на удобство и отзывчивость
3. Найти ошибки и неудобства
4. Понять, как пользователи реально используют систему
5. Собрать обратную связь для улучшения

---

## Что тестируется?

- **Web UI:** Авторизация, чат, управление API-ключами, переключение моделей
- **API:** Доступность, скорость, корректность ответов
- **Модели:** Качество ответов qwen3-32b (чат) и qwen3.8-27b (completion)
- **Аутентификация:** Работа учётных записей (Web UI) и API-ключей (`aither_`-токенов)
- **Документация:** Понятность и полнота инструкций
- **Две зоны доступа:** Internet и Test Zone
- **Инфраструктура:** Стабильность под нагрузкой

## Что НЕ следует делать?

1. ❌ **Не передавайте свои учётные данные** (логин/пароль) другим людям
2. ❌ **Не публикуйте API-ключи** в открытых источниках (GitHub, чаты, форумы)
3. ❌ **Не пытайтесь взломать систему** (тестирование безопасности НЕ входит в ваши задачи)
4. ❌ **Не нагружайте систему намеренно** (стресс-тесты проводит команда)
5. ❌ **Не используйте чужие учётные записи или API-ключи**
6. ❌ **Не передавайте конфиденциальные данные** через Web UI или API (тестовая среда!)
7. ❌ **Не ожидайте Production-надёжности** — это Beta, возможны сбои
