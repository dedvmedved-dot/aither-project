## Что такое Aither?

**Aither** — это внутренняя платформа для работы с AI-моделями (LLM). Она предоставляет доступ к большим языковым моделям через стандартный API, совместимый с OpenAI.

Проще говоря: вы отправляете текст, модель отвечает. Вы можете:
- Вести диалог с моделью (чат)
- Генерировать текст (completion)
- Использовать разные модели для разных задач

---

## Зачем проводится Closed Beta?

Перед тем как открыть доступ для всех, мы проводим **закрытое тестирование** с ограниченной группой пользователей (до 5 человек).

**Цели тестирования:**
1. Проверить стабильность системы под реальной нагрузкой
2. Найти ошибки и неудобства
3. Понять, как пользователи реально используют систему
4. Собрать обратную связь для улучшения

---

## Что тестируется?

- **API:** Доступность, скорость, корректность ответов
- **Модели:** Качество ответов qwen-14b (чат) и qwen-32b-base (completion)
- **Аутентификация:** Работа персональных API-ключей
- **Документация:** Понятность и полнота инструкций
- **Инфраструктура:** Стабильность под нагрузкой

## Что ожидается от вас?

Как участник Closed Beta, вы:

1. ✅ **Получаете персональный API-ключ** от владельца проекта
2. ✅ **Изучаете документацию** (этот пакет)
3. ✅ **Выполняете тестовые задания** из [TEST ASSIGNMENT](05_TEST_ASSIGNMENT.md)
4. ✅ **Сообщаете о проблемах** через [BUG REPORT TEMPLATE](06_BUG_REPORT_TEMPLATE.md)
5. ✅ **Заполняете обратную связь** через [FEEDBACK FORM](07_USER_FEEDBACK_FORM.md)
6. ✅ **Используете систему в реальных задачах** (по желанию)

## Что НЕ следует делать?

1. ❌ **Не передавайте свой API-ключ** другим людям
2. ❌ **Не публикуйте API-ключ** в открытых источниках (GitHub, чаты, форумы)
3. ❌ **Не пытайтесь взломать систему** (тестирование безопасности НЕ входит в ваши задачи)
4. ❌ **Не нагружайте систему намеренно** (стресс-тесты проводит команда)
5. ❌ **Не используйте чужие API-ключи**
6. ❌ **Не передавайте конфиденциальные данные** через API (тестовая среда!)
7. ❌ **Не ожидайте Production-надёжности** — это Beta, возможны сбои
