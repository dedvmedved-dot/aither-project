# Работа с моделями

**Версия:** CB-WEBUI-03
**Дата:** август 2026

Документ описывает актуальный каталог моделей Aither — только текущие, проверенные модели.

---

## Активные модели

| ID модели (API) | Отображаемое имя | Квантование | Контекст (max-model-len) | Scope |
|---|---|---|---|---|
| `qwen3-32b` | Qwen3-32B | AWQ 4-bit | 65536 токенов (64K) | `model:qwen3:chat` |
| `qwen3.8-27b` | Qwen3.8-27B | FP8 | 16384 токенов (16K) | `model:qwen3:chat` |

Обе активные модели используют единый scope API-ключей — `model:qwen3:chat`.

Qwen2.5 (ранее `qwen2.5-32b-instruct`) больше не является активной моделью и недоступна для выбора.

---

## Как выбрать модель в портале

Во вкладке «Чат» есть выпадающий список моделей. Список формируется из актуального каталога моделей, который портал получает от API (`/api/api/v1/models`), а не хранится как статический список на странице.

- Выберите модель перед отправкой сообщения.
- Новые чаты используют активную модель по умолчанию (`qwen3-32b`).
- При переключении между сохранёнными чатами модель сессии восстанавливается только если она ещё присутствует в актуальном каталоге; в противном случае выбор переносится на активную модель.
- Если каталог моделей не удаётся загрузить, отправка сообщений отключается (без подмены на неизвестную модель).

---

## API-ключ и scope

Для доступа к моделям через API требуется API-ключ (Bearer-токен). Ключ создаётся в портале: вкладка «🔑 API Ключи» → «Создать новый ключ».

Обе активные модели покрываются одним scope: `model:qwen3:chat`. При создании ключа выберите модели Qwen3-32B и/или Qwen3.8-27B — ключ получит scope `model:qwen3:chat`.

Полный ключ показывается только один раз при создании — сохраните его сразу.

## Примеры запросов

Внешний OpenAI-совместимый endpoint: `POST /api/api/v1/chat/completions`.

Список доступных моделей: `GET /api/api/v1/models`.

### Qwen3-32B

```bash
curl -X POST https://fb1.spb.ru:10443/api/api/v1/chat/completions \
  -H "Authorization: Bearer aither_..." \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3-32b","messages":[{"role":"user","content":"Привет"}]}'
```

### Qwen3.8-27B

```bash
curl -X POST https://fb1.spb.ru:10443/api/api/v1/chat/completions \
  -H "Authorization: Bearer aither_..." \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-27b","messages":[{"role":"user","content":"Привет"}]}'
```

### Стриминг

Поддерживается потоковый ответ (Server-Sent Events): добавьте `"stream": true` в тело запроса. По умолчанию ответ не-стриминговый.

## Какую модель выбрать

- **Qwen3-32B** (`qwen3-32b`) — AWQ 4-bit, максимальная длина контекста 64K токенов. Подходит для длинных диалогов и больших документов.
- **Qwen3.8-27B** (`qwen3.8-27b`) — FP8, максимальная длина контекста 16K токенов. Более компактная модель для стандартных запросов.

---

## Ошибки при неизвестной/недоступной модели

- Указание модели, отсутствующей в активном каталоге, возвращает ошибку `model_not_found` (HTTP 400/404) — запрос не отправляется на backend.
- Отсутствие scope `model:qwen3:chat` возвращает HTTP 403 (`entitlement_missing`).
- Отсутствие или неверный API-ключ возвращает HTTP 401.
