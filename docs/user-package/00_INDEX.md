## Как использовать

1. Начните с **[01_WELCOME](01_WELCOME.md)** — поймите, зачем вы здесь
2. Выполните **[02_QUICK_START](02_QUICK_START.md)** — первый запрос за 5 минут
3. Изучите **[03_USER_GUIDE](03_USER_GUIDE.md)** — полные возможности системы
4. Выполните **[05_TEST_ASSIGNMENT](05_TEST_ASSIGNMENT.md)** — обязательные задания
5. Заполните **[07_FEEDBACK_FORM](07_USER_FEEDBACK_FORM.md)** — обратная связь
6. При ошибках — **[06_BUG_REPORT_TEMPLATE](06_BUG_REPORT_TEMPLATE.md)**

## Контакты

- **Поддержка:** через установленный канал связи с владельцем проекта
- **Срочные проблемы:** немедленно сообщать владельцу проекта
- **API ключ утерян/скомпрометирован:** запросить новый через владельца
