## Назначение системы

Aither — это платформа для работы с большими языковыми моделями (LLM) через OpenAI-совместимый API. Вы отправляете текст — модель генерирует ответ.

**Основные применения:**
- Диалоги и вопросно-ответные системы
- Генерация и продолжение текста
- Помощь в написании кода
- Перевод текста
- Создание резюме и аннотаций

|---|---|
| Чат-диалоги с qwen-14b | ✅ Доступно |

| Русский язык | ✅ Поддерживается |
| Английский язык | ✅ Поддерживается |
| Контекст до 4096 токенов | ✅ Доступно |

---

## Ограничения

| Ограничение | Детали |
|---|---|
| Максимум пользователей | 5 (Closed Beta) |
| Лимит запросов | 300 запросов/минуту, burst 20 |
| Контекстное окно | 4096 токенов |
| Одновременные запросы | До ~4 параллельных на 14B (очередь GPU) |
| История диалогов | Не сохраняется между запросами (stateless) |
| Потоковая передача (streaming) | Не поддерживается |
| Function calling / tools | Не поддерживается |
| `/v1/completions` | Недоступен. Используйте `/v1/chat/completions` |

## Поддерживаемые модели

### qwen-14b (рекомендуемая)

| Параметр | Значение |
|---|---|
| **ID модели** | `qwen-14b` |
| **Тип** | Instruct (чат-модель) |
| **Контекст** | 4096 токенов |
| **Языки** | Русский, английский, китайский |
| **Для чего** | Диалоги, ответы на вопросы, написание текстов |

### qwen-32b-base

| Параметр | Значение |
|---|---|
| **ID модели** | `qwen-32b-base` |
| **Тип** | Base (completion) |
| **Контекст** | 4096 токенов |
| **Языки** | Русский, английский, китайский |
| **Для чего** | Продолжение текста, генерация |
| **⚠️ Важно** | Не оптимизирована для диалогов. Ответы в формате completion. |

## Поддерживаемые сценарии

### ✅ Сценарий 1: Диалог с моделью
Задавайте вопросы, уточняйте, ведите беседу.
```
Модель: qwen-14b
Эндпоинт: POST /v1/chat/completions
```

### ✅ Сценарий 2: Написание текста
Попросите модель написать письмо, статью, пост.
```
Модель: qwen-14b
Пример: "Напиши официальное письмо о переносе встречи"
```

### ✅ Сценарий 3: Помощь с кодом
Попросите написать или объяснить код.
```
Модель: qwen-14b
Пример: "Напиши функцию на Python для сортировки списка словарей по ключу"
```

### ✅ Сценарий 4: Перевод текста
Переводите текст между языками.
```
Модель: qwen-14b
Пример: "Переведи на английский: Добро пожаловать в Aither"
```

### ✅ Сценарий 5: Резюме текста
Попросите модель сократить длинный текст.
```
Модель: qwen-14b
Пример: "Сделай краткое резюме следующего текста: [текст]"
```

### ✅ Сценарий 6: Продолжение текста
Дайте модели начало — она продолжит.
```
Модель: qwen-32b-base
Пример: "Продолжи: Искусственный интеллект — это..."
```

## Неподдерживаемые сценарии

### ❌ Сценарий 1: Многошаговые диалоги с памятью
Система не сохраняет историю между запросами. Каждый запрос — новый.
**Обходной путь:** Передавайте историю в `messages` самостоятельно.

### ❌ Сценарий 2: Потоковая передача (streaming)
`stream: true` не поддерживается. Ответ приходит целиком.

### ❌ Сценарий 3: Вызов функций (function calling)
Модель не может вызывать внешние функции или API.

### ❌ Сценарий 4: Загрузка файлов
API не поддерживает загрузку файлов. Только текст.

### ❌ Сценарий 5: Тонкая настройка модели
Модели предоставляются «как есть». Тонкая настройка недоступна.

## Аутентификация

Каждый запрос должен содержать заголовок:

```
Authorization: Bearer ВАШ_API_КЛЮЧ
```

API-ключ выдаётся персонально владельцем проекта.

**Формат ключа:** `aither_XXXXXXXX_<секретная часть>`

**Без ключа** — `HTTP 401`.
**Неверный ключ** — `HTTP 401`.
**Просроченный/отозванный ключ** — `HTTP 401`.

Подробнее в [SECURITY RULES](09_SECURITY_RULES.md).

## Формат запросов и ответов

### Запрос (chat completions)
```json
{
  "model": "qwen-14b",
  "messages": [
    {"role": "user", "content": "Ваш вопрос"}
  ],
  "max_tokens": 200
}
```

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | Да | ID модели (`qwen-14b` или `qwen-32b-base`) |
| `messages` | array | Да | Список сообщений. Каждое: `{"role": "user", "content": "..."}` |
| `max_tokens` | integer | Нет | Максимальное количество токенов в ответе (по умолчанию 2048) |
| `temperature` | float | Нет | «Креативность» (0.0–2.0, по умолчанию 0.7) |

### Ответ
```json
{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "model": "qwen-14b",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "Текст ответа модели"
    },
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 30,
    "completion_tokens": 100,
    "total_tokens": 130
  }
}
```

## Рекомендации

1. **Для диалогов используйте qwen-14b** — она оптимизирована для общения.
2. **Для продолжения текста — qwen-32b-base** — более мощная, но базовая модель.
3. **Не делайте больше 4 одновременных запросов** к 14B — запросы встают в очередь.
4. **Делайте паузы между запросами** при интенсивном использовании.
5. **Проверяйте `finish_reason`** в ответе: `"stop"` — успешно, `"length"` — ответ обрезан.
6. **Сохраняйте ID запроса** (`id` в ответе) — пригодится для баг-репортов.

## Коды ошибок

| Код | Описание | Что делать |
|---|---|---|
| 200 | Успех | Всё работает ✅ |
| 401 | Неверный или отсутствующий API-ключ | Проверьте ключ, формат: `aither_...` |
| 404 | Модель не найдена | Проверьте `model` в запросе. Доступны: `qwen-14b`, `qwen-32b-base` |
| 422 | Неверный формат запроса | Проверьте JSON: обязательны `model` и `messages` |
| 429 | Слишком много запросов | Подождите минуту, лимит: 300/мин |
| 500 | Внутренняя ошибка сервера | Сообщите через [BUG REPORT](06_BUG_REPORT_TEMPLATE.md) |
| 504 | Таймаут шлюза | Модель не успела ответить. Повторите позже |
