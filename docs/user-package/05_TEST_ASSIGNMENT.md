## Задание 1: Вход в Web UI

**Цель:** Проверить доступность Web UI и корректность учётных данных.

### Порядок действий

1. Откройте браузер и перейдите по адресу: `https://fb1.spb.ru:443/`
2. Введите выданные **имя пользователя** и **пароль**
3. Нажмите **«Войти»**
4. Убедитесь, что открылась панель управления

### Ожидаемый результат
- Успешный вход без ошибок
- Отображается панель управления
- Видна зона: **INTERNET** (зелёный бейдж)
- Отображается список моделей (qwen-14b, qwen-32b-base)

**Отметьте:**
- [ ] Вход выполнен успешно
- [ ] Панель управления отображается
- [ ] Зона определена как INTERNET

## Задание 2: Создать API-ключ

**Цель:** Проверить работу раздела управления API-ключами.

### Порядок действий

1. В Web UI перейдите в раздел **🔑 API Ключи**
2. Нажмите **«+ Создать новый ключ»**
3. Введите название: `Тестовый ключ`
4. Выберите модели: **Обе (14B и 32B)**
5. Нажмите **«Создать»**
6. ⚠️ **Скопируйте полный ключ** (начинается с `athr_`) и сохраните в надёжном месте
7. Убедитесь, что ключ появился в таблице со статусом «Активен»

### Ожидаемый результат
- Ключ создан
- Отображается префикс (первые символы `athr_...`)
- Статус: «Активен»
- Полный ключ показан один раз

**Отметьте:**
- [ ] Ключ создан успешно
- [ ] Ключ сохранён (начинается с `athr_`)
- [ ] Ключ отображается в таблице
- [ ] Статус: Активен

## Задание 3: Тест 14B через Web UI

**Цель:** Проверить работу чат-модели qwen-14b через Web UI.

### Порядок действий

1. Перейдите в раздел **💬 Чат**
2. В выпадающем списке выберите **qwen-14b (Чат)**
3. Отправьте сообщение: *«Привет! Представься и расскажи, что ты умеешь.»*
4. Дождитесь ответа
5. Скопируйте ответ (кнопка 📋)
6. Отправьте ещё 4 разных запроса на разные темы (см. таблицу ниже)

| № | Тема запроса | Ответ получен? | Осмысленный? |
|---|---|---|---|
| 1 | Приветствие | ☐ | ☐ |
| 2 | Фактический вопрос: «Какая столица Франции?» | ☐ | ☐ |
| 3 | Креативное: «Придумай название для стартапа в сфере AI» | ☐ | ☐ |
| 4 | Техническое: «Объясни, что такое REST API простыми словами» | ☐ | ☐ |
| 5 | На английском: «What is machine learning?» | ☐ | ☐ |

### Ожидаемый результат
- Все 5 запросов получают осмысленный ответ
- Ответы соответствуют темам
- Нет ошибок или таймаутов

**Отметьте:** Успешных запросов: ___/5

## Задание 4: Тест 32B через Web UI

**Цель:** Проверить работу базовой модели qwen-32b-base через Web UI.

### Порядок действий

1. В чате переключите модель на **qwen-32b-base (Базовая)**

4. Отправьте ещё 2 запроса на продолжение текста

| № | Начало текста | Ответ получен? | Продолжает текст? |

| 1 | «Искусственный интеллект — это область...» | ☐ | ☐ |

### Ожидаемый результат

## Задание 5: Многошаговый диалог с 14B

**Цель:** Проверить сохранение контекста в рамках сессии Web UI.

4. Отправьте второе сообщение: *«Как меня зовут?»*
5. Отправьте третье сообщение: *«Что я делаю?»*

- Модель «помнит» имя из первого сообщения
- Модель помнит контекст тестирования
- Ответ на четвёртый запрос релевантен предыдущему контексту

**Отметьте:**
- [ ] Модель запомнила имя
- [ ] Модель помнит контекст тестирования

## Задание 8: Отозвать API-ключ

**Цель:** Проверить механизм отзыва API-ключей.

### Порядок действий

1. Перейдите в раздел **🔑 API Ключи**
2. Найдите ключ, созданный в Задании 2 («Тестовый ключ»)
3. Нажмите **«Отозвать»**
4. Подтвердите действие
5. Убедитесь, что статус ключа изменился на «Отозван»
6. Проверьте, что ключ больше не работает — выполните API-запрос с этим ключом:

```bash
curl https://fb1.spb.ru:443/v1/models \
  -H "Authorization: Bearer ОТОЗВАННЫЙ_КЛЮЧ"
```

### Ожидаемый результат
- Статус ключа: «Отозван»
- API-запрос с отозванным ключом возвращает HTTP 401

**Отметьте:**
- [ ] Ключ отозван (статус изменился)
- [ ] Отозванный ключ возвращает HTTP 401
- [ ] Другие активные ключи продолжают работать

## Задание 9: Создать ключ для AI-агента

**Цель:** Проверить создание специализированного ключа для AI-агента.

### Порядок действий

1. Перейдите в раздел **🔑 API Ключи**
2. Нажмите **«+ Создать новый ключ»**
3. Введите название: `Ключ для AI-агента`
4. Выберите модели: **Обе (14B и 32B)**
5. Нажмите **«Создать»**
6. ⚠️ Скопируйте ключ
7. Выполните тестовый запрос через curl или Python, используя новый ключ:

```bash
curl https://fb1.spb.ru:443/v1/chat/completions \
  -H "Authorization: Bearer НОВЫЙ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen-14b","messages":[{"role":"user","content":"Привет! Ты работаешь через API-ключ?"}],"max_tokens":100}'
```

### Ожидаемый результат
- Ключ создан
- API-запрос с новым ключом возвращает HTTP 200
- Модель отвечает осмысленно

**Отметьте:**
- [ ] Ключ создан
- [ ] API-запрос успешен (HTTP 200)
- [ ] Ответ модели осмысленный
