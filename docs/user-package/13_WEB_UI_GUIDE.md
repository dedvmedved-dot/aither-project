## Общая информация

**Web UI — основной интерфейс Aither.** Через браузер вы можете:

- 💬 Вести диалоги с моделями в реальном времени
- 🔑 Создавать и управлять API-ключами (токенами)
- 📊 Видеть статус системы и доступных моделей
- 🌐 Работать в двух зонах: Internet и Test Zone

**API также доступен** для разработчиков — см. [API GUIDE](04_API_GUIDE.md).

---

## Доступ к Web UI

### Internet (публичный доступ)

```
https://fb1.spb.ru:443/
```

- Доступен из интернета
- HTTPS с **доверенным сертификатом Let's Encrypt**
- Предупреждений браузера о сертификате **быть не должно**
- Полный функционал: чат, API-ключи, статус

### Test Zone (внутренняя сеть)

```
http://10.129.13.78:30080/
```

- Доступен только из внутренней сети / VPN
- HTTP (без шифрования — только для внутреннего использования)
- Тот же функционал, что и Internet
- Зона отображается как **TEST ZONE** (жёлтый бейдж)

## Вход в систему

1. Откройте Web UI в браузере
2. Введите **имя пользователя** и **пароль** (выдаются администратором)
3. Нажмите **«Войти»**

После входа вы увидите панель управления с информацией о системе.

### При ошибке входа

| Проблема | Решение |
|---|---|
| Неверный логин/пароль | Проверьте учётные данные, обратитесь к администратору |
| Страница не открывается | Проверьте URL и подключение к интернету |
| «Ошибка авторизации» | Очистите cookies браузера, попробуйте снова |

## Чат с моделями

### Навигация

Нажмите **💬 Чат** в верхнем меню для перехода к интерфейсу диалога.

### Выбор модели

В верхней части страницы чата — выпадающий список моделей:

| Модель | Тип | Бейдж | Описание |
|---|---|---|---|
| **qwen-14b** | Чат | `Чат` | Для диалогов, вопросов-ответов, инструкций |
| **qwen-32b-base** | Базовая | `Базовая` | Для продолжения текста |

Рядом с селектором отображается подсказка о типе выбранной модели.

### Настройки

Перед отправкой можно настроить:

| Параметр | Описание | По умолчанию |
|---|---|---|
| **max_tokens** | Максимальная длина ответа | 2048 |
| **temperature** | «Креативность»: 0.0 = точно, 1.0+ = творчески | 0.7 |

### Отправка сообщения

1. Выберите модель в выпадающем списке
2. Введите сообщение в поле ввода
3. Нажмите **Enter** или кнопку **▶ Отправить**
4. Дождитесь ответа (индикатор загрузки)

### Действия с ответом

| Кнопка | Действие |
|---|---|
| 📋 **Копировать** | Копирует текст ответа модели в буфер обмена |
| **Очистить** | Очищает всю историю текущего диалога |

### Особенности моделей

| Модель | Поведение |
|---|---|
| **qwen-14b** | Ведёт диалог, отвечает на вопросы, следует инструкциям |
| **qwen-32b-base** | Продолжает текст. Дайте начало — модель напишет продолжение |

> ⚠️ При смене модели история диалога сохраняется, но контекст может быть не совсем корректным для новой модели. Рекомендуется очищать историю при переключении.

### Ошибки в чате

| Ситуация | Сообщение | Действие |
|---|---|---|
| Проблемы с авторизацией | «Ошибка авторизации. Войдите заново.» | Выйти и войти снова |
| Модель недоступна | «Модель или endpoint не найден.» | Проверить выбор модели |
| Превышен лимит | «Превышен лимит запросов. Подождите минуту.» | Подождать 60 секунд |
| Таймаут | «Таймаут — модель не успела ответить.» | Повторить позже |
| Ошибка сети | «Ошибка сети — проверьте подключение.» | Проверить интернет |

## Управление API-ключами

Страница **🔑 API Ключи** — централизованное управление токенами доступа.

### Просмотр ключей

Таблица показывает все ваши ключи:

| Колонка | Описание |
|---|---|
| **Название** | Имя, заданное при создании |
| **Префикс** | Первые символы ключа (`athr_...`) |
| **Модели** | Какие модели доступны этому ключу |
| **Статус** | Активен / Отозван |
| **Создан** | Дата создания |
| **Последнее использование** | Дата последнего запроса |

### Создание ключа

1. Нажмите **«+ Создать новый ключ»**
2. Заполните форму:
   - **Название** — описательное имя (например, «Python скрипт», «AI-агент»)
   - **Модели** — выберите из: Обе / Только 14B / Только 32B
3. Нажмите **«Создать»**
4. ⚠️ **ВАЖНО:** Полный ключ показывается **только один раз**!
5. Скопируйте ключ и сохраните в надёжном месте

**Формат ключа:** `athr_<префикс>_<секретная_часть>`

### Отзыв ключа

1. Найдите ключ в таблице
2. Нажмите **«Отозвать»**
3. Подтвердите действие в диалоге

Отозванный ключ немедленно перестаёт работать. Восстановить его нельзя — только создать новый.

### Рекомендации по управлению

| Ситуация | Рекомендация |
|---|---|
| Личное использование через API | 1 ключ |
| Разработка скриптов | Отдельный ключ |
| AI-агент | Отдельный ключ на каждого агента |
| Ключ скомпрометирован | Немедленно отозвать, создать новый |

Подробнее: [API KEY USER GUIDE](14_API_KEY_USER_GUIDE.md).

## Две зоны доступа

Aither предоставляет две точки доступа с одинаковым функционалом:

| Зона | URL | Доступ | Протокол | Бейдж |
|---|---|---|---|---|
| **Internet** | `https://fb1.spb.ru:443/` | Открытый | HTTPS (Let's Encrypt) | 🌐 INTERNET (зелёный) |
| **Test Zone** | `http://10.129.13.78:30080/` | Внутренний / VPN | HTTP | 🧪 TEST ZONE (жёлтый) |

**API-ключи работают в обеих зонах.** Один ключ — доступ везде.

**Учётная запись одна** — используйте те же логин/пароль в обеих зонах.

Подробнее: [DUAL ZONE ACCESS GUIDE](15_DUAL_ZONE_ACCESS_GUIDE.md).

## Безопасность

### В браузере

- Всегда **выходите из системы** после завершения работы (особенно на общих компьютерах)
- Не сохраняйте пароль в браузере на чужих устройствах
- Используйте приватный режим (Incognito) на общих компьютерах

### API-ключи

- Создавайте **отдельные ключи** для разных целей
- Отзывайте неиспользуемые ключи
- При компрометации — немедленно отзывайте

### Internet vs Test Zone

- **Internet:** HTTPS с доверенным сертификатом — безопасно для любых сетей
- **Test Zone:** HTTP без шифрования — только во внутренней сети / VPN

Подробнее: [SECURITY RULES](09_SECURITY_RULES.md).

## Часто задаваемые вопросы

### Как получить учётную запись?
Обратитесь к администратору проекта. Он создаст для вас логин и пароль.

### Почему сертификат доверенный?
Используется сертификат Let's Encrypt — публично доверенный центр сертификации. Браузер не должен показывать предупреждений.

### Чем отличается Internet от Test Zone?
Функционально — ничем. Test Zone доступна только из внутренней сети или через VPN.

### Как подключить AI-агента?
1. Создайте API-ключ в разделе 🔑 API Ключи
2. Используйте его в агенте как Bearer-токен
3. Подробнее: [AI AGENT CONNECTION PRIMER](16_AI_AGENT_CONNECTION_PRIMER.md)

### Почему 32B отвечает иначе?
Это базовая модель (completion), а не чат. Она продолжает текст, а не ведёт диалог. Для общения используйте 14B.

### Сохраняется ли история диалога?
Да, в рамках сессии браузера. При выходе или очистке чата — история удаляется.
