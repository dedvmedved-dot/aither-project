## Доступ к Web UI

### Internet (публичный доступ)

```
https://fb1.spb.ru:443/
```

- Доступен из интернета
- HTTPS (самоподписанный сертификат — подтвердите исключение в браузере)
- Полный функционал: чат, API-ключи, статус

### Test Zone (внутренняя сеть)

```
http://10.129.13.78:30080/
```

- Доступен только из внутренней сети / VPN
- Тот же функционал, что и Internet
- Зона отображается как **TEST ZONE** в интерфейсе

## Вход в систему

1. Откройте Web UI в браузере
2. Введите **имя пользователя** и **пароль** (выдаются администратором)
3. Нажмите **«Войти»**

После входа вы увидите панель управления.

**При ошибке входа:**
- Проверьте правильность учётных данных
- Убедитесь, что используете актуальный URL
- Обратитесь к администратору

---

## Панель управления

После входа отображается:

- **Аккаунт:** ваше имя пользователя и роль
- **Система:** версия и статус (Работает / Деградация)
- **Модели:** список доступных моделей
- **Зона:** Internet или Test Zone (автоопределение)
- **Быстрые действия:** ссылки на чат, ключи, документацию

## Чат с моделями

### Выбор модели

В верхней части страницы чата — выпадающий список:

| Модель | Тип | Описание |
|---|---|---|
| **qwen-14b** | Чат | Для диалогов, вопросов-ответов, инструкций |
| **qwen-32b-base** | Базовая | Для продолжения текста |

Рядом с селектором отображается подсказка о типе модели.

### Отправка сообщения

1. Выберите модель
2. Введите сообщение в поле ввода
3. Нажмите **Enter** или кнопку **▶ Отправить**
4. Дождитесь ответа (индикатор загрузки)

### Дополнительные возможности

- **📋 Копировать** — копирует ответ модели
- **Очистить** — очищает историю диалога
- **max_tokens** — ограничение длины ответа
- **temperature** — «креативность» (0 = точно, 1 = творчески)

### Особенности моделей

- **qwen-14b** оптимизирована для диалогов — используйте для общения
- **qwen-32b-base** базовая модель — дайте начало текста, она продолжит
- При смене модели контекст диалога сохраняется

### Ошибки

| Ситуация | Сообщение |
|---|---|
| Проблемы с авторизацией | «Ошибка авторизации. Войдите заново.» |
| Модель недоступна | «Модель или endpoint не найден.» |
| Превышен лимит | «Превышен лимит запросов. Подождите минуту.» |
| Таймаут | «Таймаут — модель не успела ответить.» |
| Ошибка сети | «Ошибка сети — проверьте подключение.» |

## Управление API-ключами

Страница **🔑 API Ключи** позволяет:

- Просматривать существующие ключи (префикс, статус, даты)
- Создавать новые ключи (с выбором моделей)
- Отзывать ключи

### Создание ключа

1. Нажмите **«+ Создать новый ключ»**
2. Введите название ключа
3. Выберите модели (обе / 14B / 32B)
4. Нажмите **«Создать»**

⚠️ **Полный ключ показывается только один раз!** Скопируйте его сразу.

### Отзыв ключа

1. Найдите ключ в таблице
2. Нажмите **«Отозвать»**
3. Подтвердите действие

Отозванный ключ немедленно перестаёт работать.

## Две зоны доступа

Aither предоставляет две точки доступа:

| Зона | URL | Доступ |
|---|---|---|
| **Internet** | `https://fb1.spb.ru:443/` | Открытый |
| **Test Zone** | `http://10.129.13.78:30080/` | Внутренний / VPN |

Интерфейс автоматически определяет зону и показывает:

- **INTERNET** (зелёный бейдж) — публичный доступ
- **TEST ZONE** (жёлтый бейдж) — тестовая сеть

**API-ключи работают в обеих зонах.** Один ключ — доступ везде.

## Часто задаваемые вопросы

### Как получить учётную запись?
Обратитесь к администратору проекта.

### Почему сертификат недействителен?
Используется самоподписанный сертификат. В Production будет заменён на публичный.

### Как подключить AI-агента?
Используйте API-ключ, созданный в Web UI. См. [16_AI_AGENT_CONNECTION_PRIMER.md](16_AI_AGENT_CONNECTION_PRIMER.md).

### Чем отличается Internet от Test Zone?
Функционально — ничем. Test Zone доступна только из внутренней сети.

### Почему 32B отвечает иначе?
Это базовая модель (не чат). Она продолжает текст, а не ведёт диалог.
