## Пример заполненного отчёта

```
Дата:           2026-07-25
Время (UTC):    14:30

Версия системы: Beta RC (U1.4)
Ваш ID:         BETA-USER-01

Модель:         qwen-32b-base
Эндпоинт:       /v1/completions

Запрос (без API-ключа):
{"model": "qwen-32b-base", "prompt": "Hello", "max_tokens": 5}

Ожидаемый результат:
HTTP 200, модель продолжает текст

Фактический результат:
HTTP 404, {"detail": "Not Found"}

HTTP-код ответа:    404

Тело ответа (ошибка):
{"detail": "Not Found"}

Можно ли повторить?     ☑ Да

Шаги для повторения:
1. Использовать POST /v1/completions вместо /v1/chat/completions
2. Отправить запрос с model=qwen-32b-base

Тяжесть:
☐ Блокирует работу полностью
☑ Мешает, но можно обойти (через /v1/chat/completions)
☐ Незначительная проблема
```
