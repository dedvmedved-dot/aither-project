## Что такое API-ключ?

**API-ключ (токен)** — это персональный идентификатор, который даёт программам и AI-агентам доступ к моделям Aither через API.

Ключ нужен для:

- 🖥️ Автоматизации через скрипты (Python, bash, PowerShell)
- 🤖 Подключения AI-агентов и OpenAI-совместимых клиентов
- 🔌 Интеграции с другими сервисами

**Для обычного использования через браузер ключ не нужен** — достаточно войти в Web UI.

---

## Формат ключа

API-ключи Aither имеют формат:

```
aither_<префикс>_<секретная_часть>
```

Пример: `aither_xxxxxxxx_<секретная_строка>`

- **`aither_`** — обязательный префикс всех ключей
- **`<префикс>`** — идентификатор ключа (отображается в Web UI)
- **`<секретная часть>`** — длинная случайная строка (никому не показывайте!)

> ⚠️ **Полный ключ показывается только один раз** — при создании. Сохраните его сразу!

## Создание ключа через Web UI

1. **Войдите в Web UI:** `https://fb1.spb.ru:10443/` (или `http://10.129.13.78:30080/` в тестовой зоне)

2. **Перейдите в раздел 🔑 API Ключи**

3. **Нажмите «+ Создать новый ключ»**

4. **Заполните форму:** укажите название и выберите модели.

5. **Нажмите «Создать»**

6. **⚠️ СКОПИРУЙТЕ КЛЮЧ НЕМЕДЛЕННО!** После закрытия окна полный ключ больше не показывается — доступен только префикс.

7. **Сохраните ключ в надёжном месте:**
   - Менеджер паролей
   - Переменная окружения: `export AITHER_API_KEY="aither_..."`

## Использование ключа

Все запросы аутентифицируются заголовком:

```
Authorization: Bearer aither_...
```

Активные модели Aither:

| Модель | Описание | Контекст |
|---|---|---|
| `qwen3-32b` | Qwen3-32B (AWQ) | 64K токенов |
| `qwen3.8-27b` | Qwen3.8-27B (FP8) | 16K токенов |

Обе активные модели используют единый scope API-ключей — **`model:qwen3:chat`**.

---

## Список моделей (GET /api/api/v1/models)

```bash
curl https://fb1.spb.ru:10443/api/api/v1/models \
  -H "Authorization: Bearer aither_..."
```

Ожидаемый ответ (HTTP 200):

```json
{"object":"list","data":[
  {"id":"qwen3-32b","object":"model","owned_by":"aither"},
  {"id":"qwen3.8-27b","object":"model","owned_by":"aither"}
]}
```

## Чат (POST /api/api/v1/chat/completions)

```bash
curl -X POST https://fb1.spb.ru:10443/api/api/v1/chat/completions \
  -H "Authorization: Bearer aither_..." \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3-32b","messages":[{"role":"user","content":"Привет"}],"max_tokens":2048}'
```

Пример на Python:

```python
from openai import OpenAI

client = OpenAI(
    api_key="aither_...",
    base_url="https://fb1.spb.ru:10443/api/v1",
)

response = client.chat.completions.create(
    model="qwen3-32b",
    messages=[{"role": "user", "content": "Привет"}],
    max_tokens=2048,
)
print(response.choices[0].message.content)
```

> 💡 `max_tokens` по умолчанию **2048**, максимум **4096**. Значения больше 4096 ограничиваются до 4096.

## Отзыв ключа

В разделе **🔑 API Ключи** нажмите «Отозвать» рядом с нужным ключом. Отозванный ключ немедленно перестаёт работать (HTTP 401).

---

## Контролируемые ошибки

| Код | Причина |
|---|---|
| `401` | Неверный/отозванный ключ, либо неверный формат |
| `403` | Нет scope `model:qwen3:chat`, организация неактивна, либо аккаунт отключён |
| `404` | Модель не найдена (`model_not_found`) |
| `400` | Некорректный запрос (например, невалидный `max_tokens`) |

## Рекомендации

1. **Создавайте отдельный ключ на каждого агента/скрипт**
2. **Никогда не публикуйте ключ** — не коммитьте его в Git, не отправляйте в чаты
3. **Отзывайте неиспользуемые ключи**
4. **Используйте `model:qwen3:chat`** — это единственный scope активных моделей
