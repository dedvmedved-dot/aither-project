## Что такое API-ключ?

**API-ключ (токен)** — это персональный идентификатор, который даёт программам и AI-агентам доступ к моделям Aither через API.

Ключ нужен для:
- 🖥️ Автоматизации через скрипты (Python, bash, PowerShell)
- 🤖 Подключения AI-агентов (Claude Code, Codex, OpenCode, Hermes Agent)
- 🔌 Интеграции с другими сервисами

**Для обычного использования через браузер ключ не нужен** — достаточно войти в Web UI.

---

## Формат ключа

API-ключи Aither имеют формат:

```
athr_<префикс>_<секретная_часть>
```

Пример: `athr_a1b2c3d4_eFgH...очень_длинная_секретная_строка...`

- **`athr_`** — обязательный префикс всех ключей
- **`<префикс>`** — 8 символов для идентификации ключа (отображается в Web UI)
- **`<секретная часть>`** — длинная случайная строка (никому не показывайте!)

> ⚠️ **Полный ключ показывается только один раз** — при создании. Сохраните его сразу!

## Создание ключа через Web UI

### Пошаговая инструкция

1. **Войдите в Web UI:** `https://fb1.spb.ru:443/`

2. **Перейдите в раздел 🔑 API Ключи** (верхнее меню)

3. **Нажмите «+ Создать новый ключ»**

4. **Заполните форму:**

   | Поле | Описание | Пример |
   |---|---|---|
   | **Название** | Описательное имя ключа. Помогает понять, для чего он используется. | `Python скрипт`, `AI-агент Claude`, `Тестовый` |
   | **Модели** | Выберите, к каким моделям ключ даёт доступ: | |
   | | • **Обе** — доступ к qwen-14b и qwen-32b-base | Рекомендуется |
   | | • **Только 14B** — только qwen-14b (чат) | Для чат-агентов |
   | | • **Только 32B** — только qwen-32b-base (completion) | Для генерации текста |

5. **Нажмите «Создать»**

6. **⚠️ СКОПИРУЙТЕ КЛЮЧ НЕМЕДЛЕННО!**

   После закрытия окна полный ключ больше **никогда не будет показан**. Вы увидите только префикс.

7. **Сохраните ключ в надёжном месте:**
   - Менеджер паролей
   - Переменная окружения: `export AITHER_API_KEY="athr_..."`
   - Файл `.env` (не коммитьте в Git!)

### Что делать, если не скопировал?

Если вы не сохранили полный ключ — отзовите его и создайте новый. Восстановить полный ключ невозможно.

## Использование ключа

Ключ используется как **Bearer-токен** в заголовке `Authorization`.

### curl

```bash
curl https://fb1.spb.ru:443/v1/chat/completions \
  -H "Authorization: Bearer athr_..." \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen-14b","messages":[{"role":"user","content":"Привет!"}]}'
```

### Python

```python
import requests
import os

KEY = os.environ.get("AITHER_API_KEY", "athr_...")
response = requests.post(
    "https://fb1.spb.ru:443/v1/chat/completions",
    headers={"Authorization": f"Bearer {KEY}", "Content-Type": "application/json"},
    json={"model": "qwen-14b", "messages": [{"role": "user", "content": "Привет!"}]}
)
print(response.json()["choices"][0]["message"]["content"])
```

## Просмотр и управление ключами

В разделе **🔑 API Ключи** Web UI вы видите таблицу со всеми вашими ключами:

| Колонка | Значение |
|---|---|
| **Название** | Имя, заданное при создании |
| **Префикс** | Первые символы ключа (`athr_XXXXXXXX`) |
| **Модели** | Какие модели доступны (Все / 14B / 32B) |
| **Статус** | 🟢 Активен / 🔴 Отозван |
| **Создан** | Дата и время создания |
| **Использован** | Дата и время последнего запроса |

> 💡 По префиксу можно идентифицировать ключ, но нельзя восстановить полный ключ.

## Отзыв ключа

Отзыв (revoke) ключа делает его недействительным. Запросы с отозванным ключом возвращают HTTP 401.

### В Web UI

1. Перейдите в раздел **🔑 API Ключи**
2. Найдите нужный ключ
3. Нажмите **«Отозвать»**
4. Подтвердите действие

### Отозвать ключ нужно если:

- Ключ был опубликован (GitHub, чат, скриншот)
- Ключ потерян (не сохранили при создании)
- Ключ больше не нужен (агент отключён)
- Подозрение на компрометацию

### Что происходит после отзыва:

- Ключ немедленно перестаёт работать
- Статус меняется на «Отозван»
- Восстановить отозванный ключ **нельзя**
- Можно создать новый ключ

## Создание ключа через BFF API

Для автоматизации можно создавать ключи через API (Backend-for-Frontend):

### Создание токена

```bash
curl https://fb1.spb.ru:443/api/v1/tokens \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Мой токен",
    "models": ["qwen-14b", "qwen-32b-base"]
  }'
```

Ответ:
```json
{
  "token": "athr_XXXXXXXX_...полный_ключ...",
  "prefix": "athr_XXXXXXXX",
  "name": "Мой токен",
  "models": ["qwen-14b", "qwen-32b-base"],
  "created_at": "2026-07-25T12:00:00Z"
}
```

### Просмотр токенов

```bash
curl https://fb1.spb.ru:443/api/v1/tokens \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ"
```

### Отзыв токена

```bash
curl -X DELETE https://fb1.spb.ru:443/api/v1/tokens/athr_XXXXXXXX \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ"
```

## Рекомендации

### ✅ Хорошие практики

| Практика | Пример |
|---|---|
| **Отдельный ключ для каждой цели** | Скрипт, агент, тестирование — разные ключи |
| **Хранить в переменных окружения** | `export AITHER_API_KEY="athr_..."` |
| **Не коммитить в Git** | Добавьте `.env` в `.gitignore` |
| **Отзывать неиспользуемые** | После завершения проекта — отзовите ключ |
| **Использовать описательные имена** | «Агент анализа кода» лучше, чем «ключ1» |

### ❌ Плохие практики

| Практика | Почему плохо |
|---|---|
| **Хардкодить ключ в коде** | Попадёт в Git, сложно сменить |
| **Один ключ на всё** | При компрометации пострадает всё |
| **Передавать ключ в мессенджерах** | Может быть перехвачен |
| **Публиковать в скриншотах** | Ключ виден всем |
| **Использовать чужие ключи** | Нарушение безопасности |

## Устранение проблем

### Ключ возвращает 401

| Причина | Решение |
|---|---|
| Ключ отозван | Проверьте статус в Web UI, создайте новый |
| Неверный формат | Проверьте заголовок: `Authorization: Bearer athr_...` |
| Опечатка в ключе | Скопируйте ключ заново (если сохранили) или создайте новый |
| Лишние пробелы | Убедитесь, что в ключе нет пробелов в начале/конце |

### Не могу создать ключ

| Причина | Решение |
|---|---|
| Достигнут лимит ключей | Отзовите неиспользуемые ключи |
| Ошибка сервера | Попробуйте позже, сообщите через Bug Report |

### Ключ не даёт доступ к модели

| Причина | Решение |
|---|---|
| При создании выбрана не та модель | Отзовите ключ и создайте новый с нужными моделями |
| Модель недоступна | Проверьте статус системы на панели управления |

### Забыл сохранить полный ключ

Отзовите ключ в Web UI и создайте новый. Полный ключ восстановить нельзя.
