## Функциональные ограничения

### `/v1/completions` недоступен

Эндпоинт `POST /v1/completions` возвращает HTTP 404.

**Workaround:** Используйте `POST /api/v1/chat/completions` для обеих моделей:
- `qwen3-32b` — работает как чат
- `qwen3.8-27b` — работает как completion (через chat-интерфейс)

**Статус:** Запланировано к исправлению.

---

### Нет потоковой передачи (streaming)

Параметр `"stream": true` не поддерживается. Ответ приходит целиком после завершения генерации.

**Влияние:** При длинных ответах пользователь ждёт весь ответ, не видя промежуточных результатов. В Web UI отображается индикатор загрузки.

---

### Нет истории диалогов через API

Система **stateless** через API — не сохраняет историю между запросами. Каждый API-запрос обрабатывается независимо.

**Workaround для API:** Передавайте историю в массиве `messages` самостоятельно.
**Workaround для Web UI:** История сохраняется в рамках сессии браузера. Используйте Web UI для многошаговых диалогов.

---

### Нет function calling / tool use

Модель не может вызывать внешние функции или API. Только текст → текст.

---

### Нет загрузки файлов

API и Web UI принимают только текст. Загрузка файлов (изображения, документы) не поддерживается.

## Ограничения Web UI

### Сессия не сохраняется между входами

При выходе из Web UI или закрытии браузера история диалога теряется. При повторном входе начинается новая сессия.

### Нет тёмной темы

Web UI работает только в светлой теме. Тёмная тема не реализована.

**Статус:** Запланировано в будущих версиях.

### Нет экспорта диалогов

Невозможно сохранить или экспортировать историю диалога из Web UI. Доступна только кнопка «Копировать» для отдельных ответов.

### Ограничение на количество API-ключей

Максимальное количество активных API-ключей на пользователя может быть ограничено. Уточняйте у администратора.

## Ограничения моделей

### qwen3.8-27b — базовая модель

Модель **не оптимизирована для диалогов**. Она продолжает текст, а не «отвечает».

**Что это значит:**
- Ответы могут быть не в формате «вопрос-ответ»
- Модель может «уходить в сторону» от темы
- Качество диалога ниже, чем у qwen3-32b

**Рекомендация:** Для диалогов всегда используйте `qwen3-32b`.

---

### Контекстное окно: 4096 токенов

Обе модели имеют контекстное окно 4096 токенов (~3000–3500 слов).

При превышении:
- Старые сообщения игнорируются
- Модель «забывает» начало диалога

---

### Очередь GPU на 14B

Модель `qwen3-32b` использует GPU последовательно. При нескольких одновременных запросах:

- 1-й запрос: ~5 сек
- 4-й запрос: ~20 сек
- 10-й запрос: ~50 сек

**Рекомендация:** Делайте паузы между запросами при интенсивном использовании.

## Инфраструктурные ограничения

### Test Zone — HTTP

Test Zone (`http://10.129.13.78:30080/`) работает по HTTP, без шифрования. Трафик не защищён на сетевом уровне.

**Рекомендация:** Используйте Test Zone только во внутренней сети / VPN. Для конфиденциальных данных — только Internet (HTTPS).

---

### Лимит запросов: 300/мин

Превышение лимита → HTTP 429.

Лимит общий на все запросы, независимо от модели и способа доступа (Web UI или API).

---

### Отсутствие Production-мониторинга

В Beta-версии:
- Нет автоматических алертов при сбоях
- Нет дашбордов для пользователей
- Мониторинг осуществляется командой вручную

---

## Ограничения Beta

### Максимум 5 пользователей

Closed Beta ограничена 5 участниками. Расширение — после перехода к Production.

### Возможны сбои

Это Beta-версия. Возможны:
- Кратковременные перебои в доступности Web UI
- Изменения в API (с уведомлением)
- Непредвиденное поведение моделей
- Сброс сессий Web UI при перезапуске сервера

### Нет SLA

Время реакции на проблемы — best effort. Критические проблемы решаются в приоритетном порядке.
