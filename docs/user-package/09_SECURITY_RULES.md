## API-ключ — ваша ответственность

Ваш персональный API-ключ — это ваш пропуск в систему. Ключ:

- Привязан к вам лично
- Даёт доступ ко всем функциям API
- Позволяет идентифицировать ваши запросы

**Вы несёте ответственность за все действия, выполненные с вашим ключом.**

---

## Не передавайте ключ

❌ **Запрещено** передавать ваш API-ключ:
- Коллегам
- Друзьям
- В мессенджерах
- По email

У каждого участника Closed Beta — **свой персональный ключ**.

---

## Не публикуйте ключ

❌ **Запрещено** публиковать ваш API-ключ:
- В GitHub (коммиты, issues, gists)
- В чатах (Telegram, Slack, Discord)
- На форумах
- В скриншотах
- В блогах и социальных сетях

**Если вы случайно опубликовали ключ — см. раздел «Что делать при компрометации».**

---

## Не используйте чужие ключи

❌ **Запрещено** использовать API-ключ другого участника, даже с его разрешения.

Каждый ключ:
- Отслеживается отдельно
- Имеет свои лимиты
- Может быть отозван независимо

---

## Конфиденциальность запросов

⚠️ **Внимание:** Aither находится в стадии Beta. Это означает:

- **Не передавайте конфиденциальные данные** через API (пароли, персональные данные, коммерческую тайну)
- **Не загружайте чувствительные документы** (система не шифрует запросы на уровне приложения)
- **Система логирует запросы** для отладки и мониторинга

Используйте Aither для тестовых, неконфиденциальных задач.

---

## Сообщайте о подозрительной активности

Немедленно сообщите владельцу проекта, если:

- Ваш ключ перестал работать без причины
- Вы получили ответ на запрос, который не делали
- Вы заметили необычную активность (частые 401 на ваш ключ)
- Кто-то попросил ваш ключ

---

## Что делать при компрометации ключа

**Если вы подозреваете, что ключ скомпрометирован:**

1. 🛑 Немедленно прекратите использование ключа
2. 📞 Сообщите владельцу проекта
3. 🔑 Владелец отзовёт старый ключ и выдаст новый
4. ✅ Начинайте использовать новый ключ

**Время реакции на компрометацию: немедленно.**

---

## HTTPS и сертификаты

- Система работает **только через HTTPS** (порт 443)
- Сертификат — **самоподписанный** (не от публичного CA)
- При использовании curl: добавляйте флаг `-k`
- При использовании Python: `verify=False`
- При использовании PowerShell: `-SkipCertificateCheck`

**Не отключайте проверку сертификата в Production-окружении** (после Beta).

---

## Не тестируйте безопасность

🚫 **Тестирование безопасности НЕ входит в задачи Closed Beta.**

Не пытайтесь:
- Сканировать порты
- Подбирать API-ключи
- Отправлять вредоносные запросы
- Искать уязвимости
- Обходить аутентификацию

Это может быть воспринято как атака и привести к блокировке.

---

## Запрещённый контент

Не используйте Aither для генерации:

- Вредоносного кода
- Спама
- Оскорбительного или дискриминационного контента
- Материалов, нарушающих законодательство

---

## Шпаргалка

| Ситуация | Действие |
|---|---|
| Забыл ключ | Запросить у владельца |
| Опубликовал ключ | Срочно сообщить владельцу |
| Ключ перестал работать | Проверить формат, сообщить владельцу |
| Подозрительная активность | Сообщить владельцу |
| Чужой ключ | Не использовать |
