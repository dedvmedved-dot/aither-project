## Web UI

### 1. Как открыть Web UI?
Откройте браузер и перейдите: `https://fb1.spb.ru:443/`. Для Test Zone: `http://10.129.13.78:30080/`.

### 2. Как войти?
Используйте логин и пароль, выданные администратором.

### 3. Почему нет предупреждения о сертификате?
Сертификат HTTPS — доверенный (Let's Encrypt). Браузер не должен показывать предупреждений.

### 4. Что делать, если не могу войти в Web UI?
Проверьте:
- Правильность логина и пароля
- Подключение к интернету
- Доступность URL (проверьте в другом браузере)
- Обратитесь к администратору, если проблема сохраняется

### 5. Чем отличается Internet от Test Zone?
Функционально — ничем. Test Zone доступна только из внутренней сети или через VPN. Интерфейс показывает зону: **INTERNET** (зелёный) или **TEST ZONE** (жёлтый).

### 6. Как переключиться между моделями в Web UI?
В чате используйте выпадающий список в верхней части страницы. Доступны: qwen-14b (Чат) и qwen-32b-base (Базовая).

### 7. Сохраняется ли история диалога в Web UI?
Да, в рамках сессии. При очистке чата или выходе из системы история удаляется.

### 8. Как скопировать ответ модели в Web UI?
Нажмите кнопку 📋 **Копировать** рядом с ответом модели.

## Доступ и аутентификация

### 9. Как получить доступ к системе?
Обратитесь к владельцу проекта. Для Web UI — выдаётся логин/пароль. Для API — создайте ключ в Web UI (раздел 🔑 API Ключи).

### 10. Что делать, если я забыл пароль?
Обратитесь к администратору для сброса пароля.

### 11. Можно ли использовать одну учётную запись с нескольких устройств?
Да, вашу учётную запись Web UI можно использовать с любого устройства. API-ключи также работают везде.

## API-ключи

### 12. Как создать API-ключ?
В Web UI: перейдите в раздел **🔑 API Ключи** → нажмите **«+ Создать новый ключ»** → введите название → выберите модели → нажмите **«Создать»**. Подробнее: [API KEY USER GUIDE](14_API_KEY_USER_GUIDE.md).

### 13. Какой формат API-ключа?
`athr_<префикс>_<секретная_часть>`. Префикс `athr_` — обязателен.

### 14. Что делать, если я потерял API-ключ?
Полный ключ показывается только при создании. Если вы его не сохранили — отзовите старый и создайте новый.

### 15. Что делать, если ключ скомпрометирован?
Немедленно отзовите его в Web UI (🔑 API Ключи → Отозвать) и создайте новый.

### 16. Как проверить, что API-ключ работает?
Выполните `GET /v1/models`. HTTP 200 = ключ работает. HTTP 401 = ключ неверный или отозван.

### 17. Можно ли создать ключ только для одной модели?
Да. При создании ключа в Web UI выберите нужные модели: обе / только 14B / только 32B.

### 18. Как отозвать API-ключ?
В Web UI: 🔑 API Ключи → найдите ключ → нажмите **«Отозвать»** → подтвердите.

## Модели

### 19. Какие модели доступны?
Две модели:
- `qwen-14b` — чат-модель, оптимизирована для диалогов
- `qwen-32b-base` — базовая модель, для продолжения текста

### 20. Какую модель выбрать?
- Для диалогов, вопросов-ответов, инструкций → `qwen-14b`
- Для продолжения текста, генерации → `qwen-32b-base`

### 21. Почему 32B отвечает «не по-человечески»?
`qwen-32b-base` — базовая модель, она не обучена вести диалог. Она просто продолжает текст. Для диалогов используйте `qwen-14b`.

### 22. Есть ли другие модели?
На данный момент — только эти две. Новые модели могут быть добавлены в будущих версиях.

### 23. Какой максимальный размер запроса?
Контекстное окно — 4096 токенов. Это примерно 3000–3500 слов на русском языке.

## Запросы и ответы

### 24. Как отправить запрос через Web UI?
Откройте Чат, выберите модель, введите текст, нажмите Enter. См. [QUICK START](02_QUICK_START.md).

### 25. Как отправить запрос через API?
Используйте curl или Python. См. [API GUIDE](04_API_GUIDE.md).

### 26. Почему ответ обрезан?
Проверьте `finish_reason` в ответе API:
- `"stop"` — модель завершила ответ
- `"length"` — ответ обрезан из-за ограничения `max_tokens`. Увеличьте `max_tokens`.

В Web UI: увеличьте значение **max_tokens** в настройках чата.

### 27. Можно ли вести многошаговый диалог?
В Web UI — да, история сохраняется в рамках сессии.
Через API — систему не хранит историю. Передавайте всю историю в массиве `messages`.

### 28. Как получить ответ в JSON?
Просто попросите модель: «Ответь в формате JSON». Модель сама структурирует ответ.

### 29. Поддерживается ли Markdown в ответах?
Да, модель может форматировать ответы с помощью Markdown: заголовки, списки, код.

## Ошибки

### 30. Что делать при HTTP 404?
Вы указали несуществующую модель. Доступны только `qwen-14b` и `qwen-32b-base`.

### 31. Что делать при HTTP 422?
Неверный формат запроса. Проверьте:
- JSON корректен?
- Поле `model` указано?
- `messages` — массив с элементами?

### 32. Что делать при HTTP 429?
Вы превысили лимит запросов (300/мин). Подождите минуту.

### 33. Что делать при HTTP 500 или 504?
Внутренняя ошибка или таймаут. Повторите запрос позже. Если повторяется — заполните [BUG REPORT](06_BUG_REPORT_TEMPLATE.md).

### 34. Что делать, если Web UI показывает «Ошибка авторизации»?
Войдите заново. Если не помогает — очистите cookies браузера и попробуйте снова.

### 35. Что делать, если чат в Web UI не отправляет сообщение?
Проверьте подключение к интернету, обновите страницу (F5). Если проблема сохраняется — сообщите через Bug Report.

## Ограничения

### 36. Сколько запросов можно делать?
До 300 запросов в минуту, до ~4 одновременных на 14B.

### 37. Почему запросы идут медленно под нагрузкой?
14B использует GPU. При нескольких одновременных запросах они встают в очередь. Ожидание до 50 секунд при 4+ параллельных запросах — норма.

### 38. Сохраняются ли мои запросы?
В Web UI — история диалога сохраняется в рамках сессии. Через API — запросы не сохраняются, каждый запрос независим.

### 39. Можно ли загружать файлы?
Нет. Только текст через Web UI или API.

## Безопасность

### 40. Нужно ли использовать HTTPS?
Да, Internet-доступ работает через HTTPS с доверенным сертификатом Let's Encrypt. Test Zone — HTTP (внутренняя сеть).

### 41. Кто видит мои запросы?
Ваши запросы видны только вам и администраторам системы. Не передавайте конфиденциальные данные.

### 42. Что делать, если я случайно опубликовал API-ключ?
Немедленно отзовите ключ в Web UI и создайте новый. Сообщите владельцу проекта.

### 43. Можно ли тестировать безопасность системы?
Нет. Тестирование безопасности не входит в задачи Closed Beta.

### 44. Безопасно ли использовать Web UI в публичных сетях?
Да, HTTPS (Internet) обеспечивает шифрование трафика. Test Zone — только во внутренней сети.
