## Подготовка к запуску Beta

### Шаг 1: Проверьте инфраструктуру

Убедитесь, что система работает:
```bash
curl -k https://fb1.spb.ru:443/v1/models \
  -H "Authorization: Bearer ТЕСТОВЫЙ_КЛЮЧ"
```
Ожидается HTTP 200.

### Шаг 2: Создайте API-ключи

Для каждого пользователя нужен персональный ключ. Свяжитесь с Hermes или администратором для создания ключей.

**Формат ключа:** `aither_XXXXXXXX_<48-символьный-секрет>`

### Шаг 3: Подготовьте канал связи

Определите, как пользователи будут:
- Получать ключи
- Отправлять Bug Report'ы
- Отправлять Feedback Forms
- Сообщать о срочных проблемах

## Выдача доступа пользователям

### Для каждого пользователя:

1. **Назначьте ID:** `BETA-USER-01`, `BETA-USER-02`, и т.д.
2. **Создайте персональный ключ** (см. выше)
3. **Передайте безопасным каналом:**
   - Персональный API-ключ
   - Ссылку на документацию (`docs/user-package/`)
   - Особо: `05_TEST_ASSIGNMENT.md` — это их главный документ
4. **Попросите подтвердить получение**
5. **Попросите выполнить Quick Start** — чтобы убедиться, что доступ работает
6. **Установите срок выполнения заданий** (рекомендуется: 3–5 рабочих дней)

## Проведение Beta

### Во время Beta:

1. **Будьте на связи** с пользователями
2. **Отвечайте на вопросы** оперативно
3. **Собирайте Bug Report'ы** по мере поступления
4. **Не исправляйте ошибки «на лету»** без уведомления пользователей
5. **Ведите журнал инцидентов**

### Критерии остановки Beta (немедленно):

- Критическая уязвимость безопасности
- Утечка API-ключа
- Повторяющиеся 5xx, делающие систему непригодной
- GPU-сбой без workaround
- >5 нерешённых критических дефектов

## Управление API-ключами

### Создание ключа (Hermes):
```python
# Через ai-platform pod
kubectl exec -n aither-inference deploy/aither-ai-platform -- python3 -c "
import sqlite3, hashlib, secrets
raw_secret = secrets.token_urlsafe(48)
hex_part = secrets.token_hex(4)
full_key = f'aither_{hex_part}_{raw_secret}'
key_prefix = f'aither_{hex_part}'
key_hash = hashlib.sha256(full_key.encode()).hexdigest()
db = sqlite3.connect('/data/ai-platform.db')
db.execute('INSERT INTO api_keys (user_id, name, key_prefix, key_hash) VALUES (?,?,?,?)',
    (1, 'beta-user-XX', key_prefix, key_hash))
db.commit()
print(full_key)
"
```

### Отзыв ключа (Hermes):
```sql
UPDATE api_keys SET revoked_at = datetime('now') WHERE key_prefix = 'aither_XXXXXXXX';
```

### Проверка активности ключей:
```sql
SELECT key_prefix, created_at, last_used_at, revoked_at FROM api_keys WHERE revoked_at IS NULL;
```

## Завершение Beta

### Когда завершать:

- Все пользователи выполнили задания
- Все Bug Report'ы собраны
- Все Feedback Forms получены
- Нет критических нерешённых проблем

### Шаги:

1. Соберите все отчёты от пользователей
2. Передайте результаты Hermes для анализа
3. Примите решение: Ready for Production / нужны доработки
4. При необходимости — отзовите все Beta-ключи
5. Сообщите пользователям о завершении

## Аварийные ситуации

### Утечка ключа:
1. Немедленно отзовите скомпрометированный ключ
2. Выдайте пользователю новый
3. Проверьте логи на предмет несанкционированного использования

### Массовый сбой:
1. Сообщите пользователям о проблеме
2. Приостановите Beta
3. Выясните причину с Hermes
4. После исправления — возобновите Beta

### Жалоба пользователя:
1. Зафиксируйте жалобу
2. Классифицируйте: баг / неудобство / предложение
3. Передайте Hermes для исправления (баги) или учтите в планах (предложения)
