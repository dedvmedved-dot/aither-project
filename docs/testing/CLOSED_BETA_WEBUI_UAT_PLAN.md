# План пользовательского тестирования (UAT) — Aither Web UI

## Назначение

План приёмочных испытаний реальными пользователями перед запуском Closed Beta.

## Тестовые профили

### UAT-USER-01 — Обычный пользователь
- Без технического опыта работы с API
- Использует только Web UI
- Выполняет базовые операции: чат, создание ключей

### UAT-USER-02 — Пользователь AI-агента
- Имеет опыт работы с API и AI-агентами
- Подключает внешнего агента через API-ключ
- Выполняет сценарии с обеими моделями

## Процедура

1. Пользователь получает URL Web UI и учётные данные
2. Выполняет сценарии согласно профилю
3. Заполняет форму результатов (CLOSED_BETA_WEBUI_UAT_RESULT_TEMPLATE.md)
4. Отмечает все проблемы и замечания

## Критерии успеха

- Все сценарии пройдены без помощи разработчика
- Критических дефектов не обнаружено
- Документация понятна пользователю
- Пользователь подтверждает готовность к использованию
