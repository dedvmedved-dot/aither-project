---

# Назначение

Настоящий комплект документов определяет требования к завершению Stage 10 проекта Aither и является нормативной документацией, подлежащей публикации в репозитории проекта.

Документы комплекта устанавливают:

- порядок публикации;
- роли и ответственность участников;
- требования к доказательной базе (Evidence);
- порядок внешнего аудита;
- критерии завершения Stage 10.

# Важно

Публикация документов сама по себе **не означает завершение Stage 10**.

Этап считается завершённым только после успешного независимого аудита и принятия решения о прохождении контрольной точки RC1.
