# 02-STAGE10-AUTHORITY

**Версия:** 1.0

## Назначение

Документ определяет полномочия участников процесса приёмки Stage 10.

## Роли

### ChatGPT
- Архитектор проекта.
- Автор требований Stage 10.
- Независимый внешний аудитор.
- Единственный участник, уполномоченный присваивать статусы PASSED и CONNECTOR VERIFIED.

### Hermes + DeepSeek
- Реализация требований.
- Подготовка доказательной базы (Evidence).
- Выполнение публикации.
- Формирование отчётов и Commit SHA.

### Owner
- Передача заданий Hermes.
- Предоставление результатов публикации.
- Инициирование внешнего аудита.

## Принцип разделения ответственности

Hermes не принимает собственные результаты.
Окончательное решение принимает только внешний аудит после независимой проверки.
