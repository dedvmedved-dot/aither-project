# 01-PUBLISHING-INSTRUCTIONS

**Версия:** 1.0

**Статус:** Нормативный документ

---

# Назначение

Документ определяет обязательный порядок публикации документации Stage 10 в репозитории проекта.

---

# Обязанности Hermes

Hermes обязан:

1. Создать отсутствующие каталоги репозитория (при необходимости).
2. Опубликовать документы без изменения их содержания.
3. Сохранить имена файлов.
4. Сохранить структуру Markdown.
5. Проверить корректность отображения заголовков, таблиц, списков и блоков кода.
6. Выполнить коммит.
7. Выполнить публикацию в удалённый репозиторий.
8. Подготовить отчёт о публикации.

---

# Запрещается

Hermes не имеет права:

- изменять смысл утверждённых требований;
- удалять разделы;
- переименовывать документы;
- объединять документы;
- вносить неутверждённые архитектурные изменения.

---

# Результаты публикации

Hermes обязан предоставить:

- Commit SHA;
- имя ветки;
- перечень опубликованных файлов;
- результаты проверки Markdown;
- краткий отчёт о публикации.

---

# Передача на аудит

После публикации ответственность за дальнейшую проверку переходит к внешнему аудитору (ChatGPT).
