# Подключение агента к Aither API

## 1. Получение API-ключа

1. Откройте дашборд Aither: **http://170.168.91.95:8083**
2. Перейдите на вкладку **«Организация»**
3. Скопируйте API-ключ (формат `ak-...`)
4. Используйте его в заголовке: `Authorization: Bearer ***

## 2. Endpoint

```
http://170.168.91.95:8090/v1/chat/completions
```

API полностью совместим с **OpenAI Chat Completions API**.

## 3. Доступные модели

| model_id | Модель | Назначение |
|---|---|---|
| `qwen2.5-14b` | Qwen2.5-Coder-14B-Instruct | Код, короткие запросы, быстро |
| `qwen2.5-32b` | Qwen2.5-32B-GPTQ | Сложный анализ, длинные тексты |
| не указан / `auto` | Автовыбор | Gateway сам решает |

## 4. Примеры

### Простой запрос (авто-выбор модели)

```bash
curl http://170.168.91.95:8090/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer *** \
  -d '{
    "messages": [{"role": "user", "content": "Объясни, что такое Docker"}],
    "max_tokens": 200
  }'
```

### Принудительный выбор 32B (сложный анализ)

```bash
curl http://170.168.91.95:8090/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer *** \
  -d '{
    "model": "qwen2.5-32b",
    "messages": [{"role": "user", "content": "Сравни микросервисную и монолитную архитектуру"}],
    "max_tokens": 500
  }'
```

### Python

```python
import requests

response = requests.post(
    "http://170.168.91.95:8090/v1/chat/completions",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer ***
    },
    json={
        "model": "qwen2.5-32b",       # или не указывать — авто
        "messages": [{"role": "user", "content": "Привет!"}],
        "max_tokens": 200
    }
)

print(response.json()["choices"][0]["message"]["content"])
```

## 5. Логика авто-выбора модели

```
ЗАПРОС
  │
  ├─ Есть явный model_id? ─── ДА ──→ Использовать указанную модель
  │
  └─ НЕТ ──→ Анализ сложности запроса
                │
                ├─ Сложный (score ≥ 15) ──→  qwen2.5-32b
                │  • «сравни», «проанализируй», «объясни»
                │  • многочастный вопрос (во-первых, 1., 2.)
                │  • «напиши статью/отчёт/документ»
                │  • длинный запрос (> 600 знаков)
                │
                ├─ Код (``` в сообщении) ──→  qwen2.5-14b
                │
                └─ Короткий (< 150 знаков) ──→ qwen2.5-14b
```

## 9. Коды ошибок

| Код | Значение | Что делать |
|---|---|---|
| 200 | Успех | — |
| 401 | Нет токена | Добавить `Authorization: Bearer ***` |
| 402 | Недостаточно средств | Пополнить баланс организации |
| 403 | Нет доступа к модели | Запросить доступ у администратора |
| 429 | Rate limit | Подождать или повысить тариф |
| 502 | vLLM не отвечает | Повторить позже (сработает fallback) |
| 503 | Модель отключена | Использовать другую модель |
