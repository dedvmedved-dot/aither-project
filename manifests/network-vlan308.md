## Настройка сети при установке RED OS

```bash
# Интерфейс: один из транковых портов
# VLAN: 308
# Метод: static
IPADDR=10.129.13.171   # node01
IPADDR=10.129.13.172   # node02
NETMASK=255.255.255.0
GATEWAY=10.129.13.1
DNS1=10.129.13.65
```

## Связность с Hermes

Текущий путь: VPS1 → WireGuard (10.99.0.2) → VPS2 → Cisco-туннель (tun1) → 10.129.x.x

Для доступа к серверам после установки ОС:
- SSH ключ Hermes будет добавлен в `/root/.ssh/authorized_keys` на node01/node02
- Или VPN-туннель от VPS2 напрямую в сеть 10.129.13.0/24 (если маршрутизация позволит)
