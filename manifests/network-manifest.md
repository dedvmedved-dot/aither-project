## Доступ снаружи

Сеть 10.129.13.0/24 доступна через:
- **Cisco-туннель** (VPS2, Docker openconnect) → сеть 10.129.0.0/16
- **WireGuard** VPS1 ↔ VPS2 → VPS1 может обращаться к 10.129.0.0/16 через VPS2

Оба сервера НЕ имеют публичных IP. Весь внешний доступ:
- Для управления: через SSH-проброс VPS2 → Cisco-туннель → 10.129.13.x
- Для портала: reverse-proxy на VPS2 (публичный IP 130.17.1.90) → Cisco → 10.129.13.171:443
