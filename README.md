# Aither Project

Лабораторный журнал проекта **Aither** — исследования и автоматизация управления bare-metal серверами через BMC (OpenBMC/Redfish).

## Цели

- Подключение к BMC серверов в тестовой зоне Cisco (10.129.40.x)
- Инвентаризация аппаратного обеспечения
- Удалённое управление питанием, мониторинг, обновление прошивок
- Автоматизация через Redfish API + Hermes Agent

## Инфраструктура

| Компонент | Адрес | Роль |
|---|---|---|
| VPS1 | 170.168.91.95 | Hermes (основной), туннель HuaweiHP |
| VPS2 | 130.17.1.90 | Hermes (резерв), туннель Cisco |
| BMC-01 | 10.129.40.50 | OpenBMC (Redfish 1.9.0) |
| BMC-02 | 10.129.40.51 | OpenBMC (Redfish 1.9.0) |
