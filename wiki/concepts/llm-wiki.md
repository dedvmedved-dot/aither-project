# LLM-Wiki

База знаний платформы Aither по методологии Карпати (Karpathy LLM Wiki) —
персистентный граф взаимосвязанных Markdown-страниц.

## Принципы

- **Compile-once, query-many**: знания компилируются один раз, а не
  извлекаются заново при каждом RAG-запросе
- **Структурированные связи**: страницы связаны через `[[wikilinks]]`,
  образуя семантический граф
- **Гибридный поиск**: комбинация векторного ([[ChromaDB]]) и графового
  (wikilinks) методов даёт более релевантные результаты

## Структура

```
wiki/
├── SCHEMA.md           # Конвенции, таксономия тегов
├── index.md            # Каталог всех страниц
├── log.md              # Хронология изменений
├── entities/           # Сущности (AI Gateway, vLLM, ChromaDB, ...)
├── concepts/           # Концепции (RAG, Multi-tenant, Failover, ...)
├── comparisons/        # Сравнительный анализ
└── queries/            # Сохранённые результаты запросов
```

## Интеграция с RAG

При гибридном запросе:

1. [[AI Gateway]] выполняет векторный поиск в [[ChromaDB]]
2. Находит соответствующие wiki-страницы
3. Обходит граф на 1-hop (прямые соседи через `[[wikilinks]]`)
4. Объединяет и переранжирует результаты

Это даёт LLM как семантически близкие, так и концептуально связанные
фрагменты знаний.
