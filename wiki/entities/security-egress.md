# Security Egress

Модуль выходной фильтрации [[AI Gateway]]. Проверяет ответы vLLM
перед отправкой клиенту на наличие запрещённого контента.

## Категории фильтрации

| Категория | Примеры | Действие |
|---|---|---|
| DSP-маркеры | «для служебного пользования», «ДСП» | Блокировка 403 |
| ПДн | паспорт, СНИЛС, ИНН | Блокировка 403 |
| Системные утечки | `/etc/kubernetes/admin.conf`, токены | Блокировка 403 |
| Токсичность | оскорбления, угрозы | Блокировка 403 |

## Интеграция

- Вызывается после получения ответа от [[vLLM Inference]]
- При срабатывании: логирует событие в [[SIEM Integration]]
- Нарушения сохраняются в [[PostgreSQL]] `security_events`

## Расширение

Паттерны задаются в `gateway/security_egress.py`. Добавление новых
правил — редактирование словарей `DSP_PATTERNS`, `PII_PATTERNS`,
`SYSTEM_LEAK_PATTERNS`, `TOXIC_PATTERNS`.
