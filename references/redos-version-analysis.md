# RED OS: выбор версии для Quadro RTX 6000

## Исходные данные

GPU: **NVIDIA Quadro RTX 6000** (Turing TU102, 2018)
- Compute Capability: 7.5
- VRAM: 24 GB GDDR6
- CUDA: от 10.0
- Минимальный драйвер: 410.xx

## Сравнение версий

| Параметр | RED OS 7.3 (7.3.6) | RED OS 8.0 (8.0.2) |
|---|---|---|
| **Ядро Linux** | 6.1.128 | 6.12.21 |
| **Драйвер NVIDIA** | 535.113 | 570.144 |
| **linux-firmware** | ~2024 | 20250311 |
| **Docker** | 24.x | 28.1 |
| **Kubernetes** | 1.28 | 1.32 |
| **PostgreSQL** | 15.x | 17.5 |
| **ISO-образ** | `redos-MUROM-7.3.6-20250715.0-Everything-x86_64-DVD1.iso` | `redos-8-20250711.4-Everything-x86_64-DVD1.iso` |
| **Размер ISO** | 5.1 GB | 6.1 GB |

## Рекомендация: RED OS 8.0

**Обоснование:**

- **NVIDIA 570.144** — новейший стабильный драйвер с полной поддержкой Turing (Quadro RTX 6000), улучшенной производительностью CUDA 12.x и исправлениями безопасности
- **Ядро 6.12.21** — значительно новее: улучшенная поддержка GPU passthrough, IOMMU, cgroup v2 (необходимо для NVIDIA GPU Operator в K3s/K8s)
- **Docker 28.1 + Kubernetes 1.32** — актуальные версии для production-развёртывания GPU-нагрузок
- **linux-firmware 20250311** — новейшие прошивки для корректной инициализации GPU и управления питанием

Драйвер 535.113 (RED OS 7.3) **совместим** с RTX 6000, но является устаревшим и не обеспечивает оптимальную производительность для современных нагрузок (vLLM, CUDA 12.x).
