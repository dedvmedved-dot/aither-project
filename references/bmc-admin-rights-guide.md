# Инструкция: выдача прав администратора BMC (OpenBMC)

## Общая информация

Оба BMC доступны в браузере:
- **Сервер 1**: https://10.129.40.50
- **Сервер 2**: https://10.129.40.51

Браузер покажет предупреждение «сертификат недействителен» — нажать **«Дополнительно» → «Перейти на сайт»**.

## Вход

Использовать учётную запись с правами администратора. Если её нет — см. раздел «Сброс пароля root через Recovery Shell» в конце.

## Пошаговая инструкция (через Web UI)

### Шаг 1. Войти в веб-интерфейс

1. Открыть https://10.129.40.50
2. Войти под административной учётной записью (логин и пароль администратора)

### Шаг 2. Перейти в управление пользователями

В левом меню выбрать:
- **Access Control** → **Local User Management**
  *или*
- **Security** → **Users**

### Шаг 3. Найти учётную запись techvit

В списке пользователей найти строку **techvit**. Нажать на неё для редактирования.

### Шаг 4. Изменить роль

В карточке пользователя найти выпадающий список **Role** / **Privilege**:

Текущее значение: `Operator` или `ReadOnly`

Изменить на: **`Administrator`**

### Шаг 5. Сохранить

Нажать кнопку **Save** / **Сохранить**.

### Шаг 6. Проверить

Открыть новую вкладку в браузере, перейти на https://10.129.40.50 и войти под учётной записью **techvit**. Меню должно содержать все разделы управления, включая:
- Power Control (управление питанием)
- Virtual Media (монтирование ISO-образов)
- Sensor (датчики, температура)
- Configuration (настройки сети, безопасности)

### Шаг 7. Повторить для второго сервера

Выполнить шаги 1–6 для https://10.129.40.51

## Сброс пароля root через Recovery Shell

Если административная учётная запись утеряна:

1. Подключиться к серверу через физическую консоль (монитор+клавиатура) или Serial-over-LAN
2. Перезагрузить сервер и войти в U-Boot (прервать загрузку клавишей)
3. В U-Boot передать аргументы ядру для сброса пароля:

```
setenv bootargs $bootargs rw init=/bin/sh
boot
```

4. После загрузки в recovery shell:

```sh
mount -t proc proc /proc
mount -t sysfs sysfs /sys
passwd root          # задать новый пароль root
reboot -f
```

5. После перезагрузки войти под root → изменить роль учётной записи techvit

## Проверка результата (выполнить после выдачи прав)

Для проверки в терминале (с VPS2):

```bash
curl -sk -u "techvit:fhtfdh2!RF78" "https://10.129.40.50/redfish/v1/Systems/system" | python3 -m json.tool | head -20
```

**Ожидаемый результат:** HTTP 200 и JSON с информацией о системе (Model, SerialNumber, ProcessorSummary, MemorySummary).

Если результат **401 Unauthorized** — права не назначены, повторить инструкцию.
