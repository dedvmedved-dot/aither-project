## Детальный анализ

### 1. Вычислительные ресурсы

**ТР требует:** серверы с GPU для vLLM-инференса.

**Фактически:** 2× Xeon Gold 6258R (Cascade Lake Refresh, 28c/56t, 2.70–4.00 GHz).

**Оценка:** ✅ **С запасом.** 56 физических ядер на сервер — достаточно для:
- K3s control-plane (2–4 ядра)
- vLLM inference (задействует GPU, CPU — минимально)
- Portal BFF + Portal DB (4–8 ядер)
- Системные сервисы (2 ядра)

### 2. GPU

**ТР требует:** 4× NVIDIA RTX 6000 (Turing TU102, 24 GB GDDR6).

**Фактически:** 13 PCIe устройств, из которых предположительно 4 GPU. Vendor/Device ID не экспортируется через Redfish данной прошивки — требуется подтверждение через `nvidia-smi` после загрузки ОС.

**Оценка:** ⚠️ **Требует подтверждения.** Необходимо:
1. Загрузить RED OS
2. Установить драйверы NVIDIA
3. Выполнить `nvidia-smi` — подтвердить 4× RTX 6000

### 3. Память

**ТР требует:** «Достаточно для LLM-инференса».

**Фактически:** 768 GB DDR4-2934 (12× 64 GB Samsung ECC).

**Оценка:** ✅ **С запасом.** Для инференса 70B-модели (FP16) требуется ~140 GB. Даже с 4 параллельными моделями остаётся запас для ОС и системных сервисов.

### 4. Диски

**ТР:** не специфицирует требований к дискам.

**Фактически:** MARVELL RAID VD, 447 GB SAS (единственный видимый диск).

**Оценка:** ❌ **Критическое несоответствие.** 447 GB — это только **системный RAID**. Для Aither необходимо:

| Назначение | Мин. объём | Рекомендация |
|---|---|---|
| RED OS + системные | 100 GB | Уже есть (текущий RAID) |
| Docker-образы + модели | 500 GB | NVMe SSD |
| PostgreSQL (Portal DB) | 200 GB | NVMe SSD |
| Логи + мониторинг | 200 GB | SATA SSD |

**Необходимое действие:** уточнить у специалиста полную конфигурацию дисков.

### 5. Сеть

**ТР:** не специфицирует, но предполагает кластер K3s.

**Фактически:** VLAN 308, 10.129.13.0/24, шлюз 10.129.13.1, DNS 10.129.13.65.

**Оценка:** ✅ **Достаточно.** Для K3s-кластера из 2 узлов требуется минимум одна подсеть.

### 6. ОС

**ТР:** RedOS 7.3.

**Рекомендация:** **RedOS 8.0.2** (ядро 6.12, NVIDIA 570, Docker 28.1, K8s 1.32).

**Обоснование замены:**
- Драйвер NVIDIA 570.144 имеет полную поддержку RTX 6000 с CUDA 12.x
- Ядро 6.12.21 необходимо для NVIDIA GPU Operator
- Docker 28.1 + K8s 1.32 — актуальные production-версии
- RedOS 7.3 использует устаревшие версии (ядро 6.1, NVIDIA 535, Docker 24)

## Заключение

**ТР №1 в целом реализуемо на имеющемся оборудовании.** Единственное критическое несоответствие — дисковая подсистема (447 GB vs требуемые ~1 TB). Всё остальное — с запасом.
