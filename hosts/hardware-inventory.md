## Заключение

Два идентичных сервера YADRO VEGMAN S320:
- 2× Xeon Gold 6258R (56c/112t, 4.0 GHz Turbo) — **избыточно для K3s + vLLM**
- 768 GB DDR4-2934 — **достаточно для LLM-инференса (модели до 70B)**
- 4× RTX 6000 (96 GB VRAM) — **запуск LLaMA-70B-Q4, параллельный инференс**
- Дисковая подсистема: **~40 TB SSD суммарно** — более чем достаточно

- **VD-1 (RAID1, 2× 1.7TB)** → `/` (200G) + `/var/lib/docker` (300G) + `/var/log` (200G) + swap (128G)
- **VD-2 (RAID10, 10× 3.5TB)** → `/data/models` (5TB) + `/data/postgres` (2TB) + `/data/backup` (3TB) + `/data/k3s` (5TB)
- **M.2 (RAID1, 2× 480GB)** → `/nvme/cache` (960GB) — Docker overlay2, Redis, временные файлы
