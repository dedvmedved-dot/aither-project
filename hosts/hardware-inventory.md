## Заключение

Оба сервера — **идентичные** YADRO VEGMAN S320:
- 2× Xeon Gold 6258R (56c/112t, 4.0 GHz Turbo) — с запасом для control-plane + inference
- 768 GB DDR4-2934 — достаточно для моделей до 70B в Q4
- **2× RTX 6000 с NVLink** (48 GB объединённой VRAM) — LLaMA-70B-Q4, Qwen-72B, DeepSeek-67B
- Диски: ~19 TB usable — более чем достаточно для ОС, моделей, PostgreSQL и бэкапов
- K3s — оптимальный выбор при 2 узлах; при масштабировании до 3+ узлов переход на K8s безболезненный

### План разметки

- **VD-1 (RAID1, 2× 1.7TB)** → `/` (200G) + `/var/lib/docker` (300G) + `/var/log` (200G) + swap (128G)
- **VD-2 (RAID10, 10× 3.5TB)** → `/data/models` (5TB) + `/data/postgres` (2TB) + `/data/backup` (3TB) + `/data/k3s` (5TB)
- **M.2 (RAID1, 2× 480GB)** → `/nvme/cache` (960GB) — Docker overlay2, Redis, временные файлы
