## Метрики внедрения

| Параметр | До | После |
|---|---|---|
| Точность учёта токенов | Оценка (±30%) | Факт из vLLM (±0%) |
| Детализация | total_tokens | prompt + completion |
| Записи в БД | billing_ledger (агрегат) | + usage_records (per-request) |
| Горизонт аналитики | 48h (Redis) | 90 дней (SQL) |
| API статистики | /v1/usage/ (сводка) | + /v1/usage/stats (агрегация) |
| Строк кода Gateway | 340 | 423 (+83 строки) |
| Overhead на запрос | 0 ms | < 5 ms |

## Принятые решения

1. **Fail open при недоступности PostgreSQL** — запросы обслуживаются, запись пропускается с логом ошибки
2. **Горизонт хранения 90 дней** — сырые данные, агрегаты хранятся постоянно в billing_ledger
3. **Отказ от Lua для usage_records** — INSERT в PostgreSQL через psycopg2, без Redis-кеширования записей
4. **Модель в usage_records** — сохраняется полный путь (`/models/Qwen2.5-14B-Instruct`) для будущей мультимодельности
