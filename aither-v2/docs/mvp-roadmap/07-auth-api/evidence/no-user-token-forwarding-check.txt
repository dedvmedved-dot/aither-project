Runtime evidence:

     -> Got HTTP 401 with upstream message "Unauthorized"

     User's "Authorization: Bearer athr_xxx" is verified locally, never forwarded.

Source code:

    where ua(model) returns BFF_14B_UPSTREAM_AUTH_TOKEN or BFF_32B_GATEWAY_AUTH_TOKEN
  - _upstream_headers() function returns BFF internal credentials
  - Old _headers() from v0.3.0 that forwarded user Authorization is REMOVED
