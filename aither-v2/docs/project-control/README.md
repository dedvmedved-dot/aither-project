# Project Control Documentation

This directory is the persistent control layer for the Aither / AI Hermes MVP project.

## Purpose

These documents allow the project to continue across different ChatGPT chats, Hermes sessions, and audit cycles without losing context.

## Files

| File | Purpose |
|---|---|
| PROJECT_MASTER.md | Main project book and current state |
| ROADMAP.md | MVP and Post-MVP roadmap |
| DECISION_LOG.md | Architectural and operational decisions |
| AUDIT_LOG.md | ChatGPT audit history |
| FINDINGS.md | Open, resolved, postponed findings |
| HERMES_RULES.md | Execution rules for Hermes + DeepSeek |
| GPT_AUDIT_RULES.md | Rules for ChatGPT external audit |
| CHAT_HANDOVER.md | Minimal context for starting a new ChatGPT project/chat |

## Source of truth

GitHub is the persistent source of truth.
ChatGPT performs external audit.
Hermes performs implementation and evidence collection.
