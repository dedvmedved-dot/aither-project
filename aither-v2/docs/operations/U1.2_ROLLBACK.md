# U1.2 Rollback Plan

## VPS2 Edge Rollback

### VPN Client
- **Current image:** `vpn-cisco-o` (entrypoint: `vpn-cisco-entrypoint.sh` with `set timeout -1` fix)
- **Previous:** Same image, old entrypoint with `expect eof` bug
- **Rollback command:**
  ```bash
  docker stop vpn-cisco && docker rm vpn-cisco
  # Restore old entrypoint from backup
  cp /root/edge-backup-<timestamp>/vpn-cisco-entrypoint.sh.old /root/services/.../
  # Restart
  docker run -d --name vpn-cisco ... vpn-cisco-o
  ```
- **Risk:** Old entrypoint causes tun0 restart loop → Internet 504

### VPS2 Nginx
- **Current config:** `/root/nginx-failover.conf` (HTTP/1.1, keepalive 16, connect_timeout 30s)
- **Rollback:**
  ```bash
  docker exec aither-failover-nginx nginx -s reload
  # Or if config changed: restore from backup
  cp /root/edge-backup-<timestamp>/nginx-failover.conf /root/
  docker stop aither-failover-nginx && docker start aither-failover-nginx
  ```
- **Risk:** Old config (HTTP/1.0, keepalive 0, connect_timeout 10s) may cause intermittent 504
