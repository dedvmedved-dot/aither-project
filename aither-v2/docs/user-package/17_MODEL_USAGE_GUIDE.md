## QWEN-14B — ЧАТ-МОДЕЛЬ ДЛЯ ДИАЛОГОВ

**Что это:** Qwen2.5-14B-Instruct — instruction-tuned модель.
Обучена на диалогах, следует инструкциям, держит контекст беседы.

**Формат API:** OpenAI Chat Completions
```json
{"messages": [{"role":"user","content":"Вопрос"}, {"role":"assistant","content":"Ответ"}]}
```

**Как работает (BFF):**
Пользователь → BFF → vllm-14b:/v1/chat/completions
Сообщения передаются «как есть» с ролями user/assistant.

**Пример:**
```
Q: Привет! Как тебя зовут?
A: Привет! Меня зовут Qwen, я создана Alibaba Cloud.
```

**Когда использовать:**
- ✅ Диалоги, вопросы-ответы
- ✅ Многошаговые беседы с контекстом
- ✅ Следование инструкциям
- ✅ Объяснения, переводы, summarization

**Технические характеристики:**
- Архитектура: Qwen2.5-14B-Instruct, FP16
- Размер: 28 GB (распределён на 2×Quadro RTX 6000 через tensor-parallel)
- Контекстное окно: 4096 токенов
- Скорость генерации: ~0.1 сек/токен
- Размещение: N8, GPU#0 + GPU#1

## QWEN-32B-BASE — БАЗОВАЯ МОДЕЛЬ (ПРОДОЛЖЕНИЕ ТЕКСТА)

**Что это:** Qwen2.5-32B-GPTQ-Int4 — базовая (base) модель.
НЕ обучена диалогам и следованию инструкциям!

**Формат API:** Text Completions
```json
{"prompt": "Начало текста..."}
```

**Как работает (BFF):**
Адаптер BFF преобразует диалог в промпт. Формат промпта:
```
<|user|>
Сообщение пользователя
<|assistant|>
```
Модель просто ПРОДОЛЖАЕТ текст с того места, где он остановился.
В ответе может содержаться текст промпта — это нормально для base-модели.

**Пример completions (хороший):**
```
Prompt:    «Столица России —»
Completion: «Москва. Это один из самых больших городов России.»
```

**Пример кода:**
```
Prompt:    «def fibonacci(n):»
Completion: «    if n <= 1:\n        return n\n    else:\n        return fibonacci(n-1) + fibonacci(n-2)»
```

**Пример перевода:**
```
Prompt:    «English: Hello, how are you?\nRussian:»
Completion: «Здравствуйте, как дела?»
```

**Когда использовать:**
- ✅ Генерация / продолжение кода
- ✅ Дописывание текста
- ✅ Перевод (prompt: "English: Hello\nRussian:")
- ✅ Креативное письмо (prompt: "Глава 1.\n")
- ❌ Диалоги — модель не понимает вопросов
- ❌ Инструкции — не выполняет команды

**Технические характеристики:**
- Архитектура: Qwen2.5-32B-Instruct, GPTQ Int4
- Размер: 19 GB (влезает в одну GPU)
- Контекстное окно: 4096 токенов
- Скорость генерации: ~0.06 сек/токен
- Размещение: N7, GPU#1

## ПОЧЕМУ ТАК?

**14B Instruct** — это модель, прошедшая instruction tuning (SFT + RLHF).
Её учили отвечать на вопросы и вести диалог.

**32B Base** — это «сырая» языковая модель без выравнивания.
Она умеет только продолжать текст. Это как автодополнение в телефоне,
но на уровне целых абзацев и с пониманием структуры кода.

Размер 32B даёт лучшее качество генерации кода и сложного текста,
поэтому используется GPTQ-квантование для размещения в 22 GB VRAM.

14B Instruct работает на N8 с tensor-parallel=2 (44 GB VRAM), что
позволяет загрузить модель без CPU-offloading и достичь высокой скорости.

## КАК ИСПОЛЬЗОВАТЬ

**Через портал (вкладка Чат):**
Выберите модель в выпадающем списке:
- qwen-14b (Чат) — для диалогов
- qwen-32b-base (Базовая) — для продолжения текста

**Через API:**
```bash
# 14B — диалог
curl -X POST https://fb1.spb.ru/api/v1/chat \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"model":"qwen-14b","messages":[{"role":"user","content":"Привет"}]}'

# 32B — продолжение текста
curl -X POST https://fb1.spb.ru/api/v1/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"model":"qwen-32b-base","prompt":"Напиши функцию:"}'
```
