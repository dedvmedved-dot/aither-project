API Access Guide

Agents and external tools can access Aither models through the BFF API using Bearer tokens.

Authentication

All API requests (except /health and /api/v1/auth/login) require a valid API token.

Authorization: Bearer athr_<your_token>

Create tokens in the Tokens page. The raw token is shown only once — copy it immediately.

Endpoints

List Models

GET /api/v1/models
Authorization: Bearer athr_<token>

Chat (14B native, 32B adapter)

POST /api/v1/chat
Authorization: Bearer athr_<token>
Content-Type: application/json

{
  "model": "14b",
  "messages": [{"role": "user", "content": "Hello"}]
}

Completions (32B only)

POST /api/v1/completions
Authorization: Bearer athr_<token>
Content-Type: application/json

{
  "model": "32b",
  "prompt": "Once upon a time"
}

Token Management

POST   /api/v1/tokens           # Create token
GET    /api/v1/tokens           # List tokens (metadata only)
DELETE /api/v1/tokens/{id}      # Revoke token
Note: Raw API tokens are not stored on the server after creation. The raw token is only returned once in the create response. Store it securely. If lost, revoke the token and create a new one.
