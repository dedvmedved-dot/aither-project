🧠 RAG — Wiki-Graph: инструкция

Что такое RAG?

RAG (Retrieval-Augmented Generation) — технология, которая дополняет ответы модели актуальной информацией из вашей базы знаний.

Вместо того чтобы полагаться только на знания модели, RAG находит релевантные документы в Wiki-Graph и включает их в контекст запроса.

Как использовать RAG в чате

1. Откройте вкладку 💬 Чат

2. Введите поисковый запрос в поле «🔍 RAG-поиск» над областью сообщений

3. Нажмите «Искать в RAG» — система найдёт релевантные документы

4. Результаты появятся над областью чата

5. Теперь модель будет учитывать найденную информацию при ответе

Использование вкладки RAG

1. Перейдите на вкладку 🧠 RAG

2. Введите запрос в поле поиска

3. Нажмите «Искать»

4. Система выполнит гибридный поиск (векторный + графовый + текстовый) по всем документам

5. Результаты покажут наиболее релевантные фрагменты

Wiki-Graph

📚 Wiki-Graph — граф знаний, связывающий документы по темам и ссылкам.

Используйте вкладку 📚 Wiki для навигации по графу знаний, поиска по страницам и просмотра связанных документов.

Требования

Для использования RAG необходимы:

• Тариф Free или выше

• Scope rag:query в настройках пользователя

• Подключение к ChromaDB (векторная БД)
