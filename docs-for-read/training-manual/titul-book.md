## Аннотация

Учебное пособие описывает полный цикл создания платформы **Aither** —
Token-as-a-Service системы для продажи токенов к большим языковым моделям
(LLM) через OpenAI-совместимый API.

Платформа построена на стеке: **Astra Linux SE 1.8 → Kubernetes → vLLM →
Python API Gateway → Node.js Portal**. Обеспечивает мультитенантную изоляцию
организаций, тарификацию по токенам, интеграцию с YooKassa, enterprise-безопасность
(mTLS, DLP, SIEM) и гибридный RAG-поиск (wiki-граф + ChromaDB).

**Учебник состоит из 4 частей:**

| Часть | Глав | Стр. | Содержание |
|---|---|---|---|
| I. Теоретические основы | 1–7 | ~170 | От процессора до архитектуры Aither |
| II. Практическое развёртывание | 8–13 | ~150 | Пошаговый деплой всей системы |
| III. Разработка и доработка | 14–18 | ~95 | Код, модели, CI/CD |
| IV. Production-эксплуатация | 19–24 | ~190 | HA, мультитенатность, RAG, приёмка |
| Приложения + Практикум | — | ~135 | Глоссарий, шпаргалки, 20 ЛР |

**Учебник написан на основе реального кода** — каждый фрагмент взят
из работающей системы. Читатель может открыть соответствующий файл
в репозитории и увидеть полный контекст.

## Как собирается учебник

```bash
# 1. Объединяем все части в один Markdown
cat 00-master-toc.md \
    01-part1-theory.md \
    02-part2-deployment.md \
    03-part3-development.md \
    05-part4-production.md \
    04-appendices-labs.md \
    > aither-full.md

# 2. Конвертируем в DOCX (pandoc)
pandoc aither-full.md -o aither-textbook.docx \
    --from markdown --to docx \
    --reference-doc=template.docx

# 3. Конвертируем в PDF
pandoc aither-full.md -o aither-textbook.pdf \
    --from markdown --pdf-engine=xelatex \
    -V mainfont="Times New Roman" \
    -V fontsize=12pt
```
