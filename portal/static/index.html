Формат авторизации:

Authorization: Bearer <YOUR_API_KEY>

Пример curl:

curl <API_URL>/v1/chat/completions \
  -H "Authorization: Bearer $AITHER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen-14b","messages":[{"role":"user","content":"Hello"}]}'
🔑 Как получить ключ: Перейдите в раздел 🔑 API Ключи, создайте ключ для нужной модели, скопируйте его и используйте здесь.

Internet Zone: https://fb1.spb.ru:443

Test Zone: http://10.129.13.78:30080

API совместимость: OpenAI-compatible (/v1/chat/completions, /v1/models)

Правила хранения ключа: Храните ключ в переменных окружения (export AITHER_API_KEY="..."). Не сохраняйте в коде.

Отзыв ключа: В разделе 🔑 API Ключи нажмите «Отозвать».
