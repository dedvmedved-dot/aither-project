# CB-WEBUI-01 — Известные ограничения

## Критические (блокирующие)

На данный момент критических блокирующих ограничений не выявлено. Все основные функции работают.

## Средние (ограничивающие)

### 1. Страница API-ключей не загружается

| Параметр | Значение |
|----------|----------|
| **Симптом** | При переходе на «🔑 API Ключи» отображается «Не удалось загрузить ключи» |
| **Причина** | BFF-эндпоинт `GET /api/v1/tokens` может быть не полностью реализован |
| **Влияние** | Невозможно просмотреть существующие ключи через Web UI |
| **Обходной путь** | Использовать прямые API-запросы к BFF через curl |
| **План исправления** | CB-WEBUI-02 — полная имплементация CRUD для `/api/v1/tokens` |
| **Приоритет** | 🟡 Средний |

### 2. 32B-модель работает только в режиме completion

| Параметр | Значение |
|----------|----------|
| **Симптом** | qwen-32b-base не поддерживает диалоговый режим, только продолжение текста |
| **Причина** | Базовая модель (base), не fine-tuned для инструкций/чата |
| **Влияние** | Невозможно вести полноценный диалог с 32B-моделью |
| **Обходной путь** | Использовать qwen-14b для диалогов, 32B — для генерации текста |
| **План исправления** | Развернуть instruct-версию 32B или chat-adapter |
| **Приоритет** | 🟡 Средний |

### 3. Отсутствует streaming-режим (SSE)

| Параметр | Значение |
|----------|----------|
| **Симптом** | Ответы моделей приходят целиком, а не токен за токеном |
| **Причина** | Фронтенд ожидает полный JSON-ответ, нет SSE-парсинга |
| **Влияние** | Пользователь ждёт полный ответ (4-5 секунд), нет ощущения «живого» ответа |
| **Обходной путь** | Нет |
| **План исправления** | Добавить SSE-клиент на фронтенде, поддержку `stream: true` в API |
| **Приоритет** | 🟡 Средний |

### 4. Нет индикации набора текста (typing indicator)

| Параметр | Значение |
|----------|----------|
| **Симптом** | После отправки сообщения показывается «⏳ Генерация ответа...» без анимации |
| **Причина** | Упрощённая реализация — статичный текст вместо анимированного индикатора |
| **Влияние** | UX-недостаток: пользователь не видит прогресса |
| **Обходной путь** | Нет |
| **План исправления** | Добавить анимированный индикатор с точками или пульсацией |
| **Приоритет** | 🟢 Низкий |

## Низкие (косметические)

### 5. Отсутствует тёмная/светлая тема

| Параметр | Значение |
|----------|----------|
| **Симптом** | Всегда тёмная тема, нет переключателя |
| **Причина** | Не реализовано |
| **Влияние** | Минимальное |
| **Приоритет** | 🟢 Низкий |

### 6. Нет мобильной адаптации

| Параметр | Значение |
|----------|----------|
| **Симптом** | На мобильных устройствах интерфейс может быть неудобным |
| **Причина** | Нет медиа-запросов для mobile-first |
| **Обходной путь** | Использовать с десктопа |
| **Приоритет** | 🟢 Низкий |

### 7. Нет истории чатов между сессиями

| Параметр | Значение |
|----------|----------|
| **Симптом** | При выходе история чата очищается (`chatHistory = []`) |
| **Причина** | История хранится только в памяти (нет персистентности) |
| **Влияние** | После перезагрузки страницы история теряется |
| **Приоритет** | 🟢 Низкий |

### 8. Ограничение контекста — 20 сообщений

| Параметр | Значение |
|----------|----------|
| **Симптом** | При длинном диалоге старые сообщения выпадают из контекста |
| **Причина** | `chatHistory.slice(-20)` — жёсткое ограничение |
| **Влияние** | Модель «забывает» начало длинного диалога |
| **Приоритет** | 🟢 Низкий |

### 9. Нет валидации API-ответов

| Параметр | Значение |
|----------|----------|
| **Симптом** | При неожиданном формате ответа от BFF — ошибка парсинга |
| **Причина** | Нет схемы валидации JSON-ответов |
| **Влияние** | Возможны неожиданные ошибки при изменении API |
| **Приоритет** | 🟢 Низкий |

## Риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| BFF не реализует `/api/v1/tokens` | Средняя | Среднее | Прямые API-запросы как обходной путь |
| Изменение формата API BFF | Низкая | Высокое | Добавить валидацию ответов |
| Проблемы с SSL-сертификатом | Низкая | Высокое | Автоматическое обновление через Let's Encrypt |
| VPS2 недоступен | Низкая | Высокое | Тестовая зона доступна напрямую |

## Заключение

CB-WEBUI-01 не имеет критических блокирующих ограничений. Основные проблемы связаны с неполной готовностью бэкенда (BFF `/api/v1/tokens`) и отсутствием streaming-режима. Оба ограничения запланированы к исправлению в CB-WEBUI-02.
