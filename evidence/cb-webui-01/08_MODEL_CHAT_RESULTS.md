# CB-WEBUI-01 — Результаты тестирования чата с моделями

## Сводка

Обе модели (qwen-14b и qwen-32b-base) протестированы через Web UI. Обе возвращают ответы на русском языке.

| Модель | Режим | Язык ответа | Скорость | Статус |
|--------|-------|-------------|----------|--------|
| `qwen-14b` | Chat completions | Русский ✅ | ~4 сек | ✅ PASS |
| `qwen-32b-base` | Text completion | Русский ✅ | ~5 сек | ✅ PASS |

## qwen-14b (Чат-модель)

### Характеристики

| Параметр | Значение |
|----------|----------|
| ID модели | `qwen-14b` |
| Тип | Chat completions (диалоговая) |
| Режим | `messages[]` — многооборотный диалог |
| Контекст | 20 последних сообщений |
| Параметры по умолчанию | `max_tokens=512`, `temperature=0.7` |
| Описание в UI | «Чат-модель — оптимизирована для диалогов» |

### Тестовые запросы

#### Запрос 1: Приветствие

```
Модель: qwen-14b
Запрос: "Привет! Расскажи о платформе Aither."
Температура: 0.7
Max tokens: 512
```

**Ответ:** Модель ответила на русском языке в диалоговом стиле. Ответ содержал описание платформы, её возможностей и архитектуры. Длина ответа: ~150-200 токенов.

**Результат:** ✅ PASS — осмысленный диалоговый ответ на русском языке.

#### Запрос 2: Технический вопрос

```
Модель: qwen-14b
Запрос: "Какие языковые модели поддерживает Aither?"
Температура: 0.7
Max tokens: 512
```

**Ответ:** Модель корректно ответила о поддержке Qwen 14B и Qwen 32B Base.

**Результат:** ✅ PASS — контекстный ответ с учётом специфики платформы.

#### Запрос 3: Многооборотный диалог

```
Сообщение 1: "Привет!"
Ответ 1: "Здравствуйте! Чем могу помочь?"

Сообщение 2: "Что такое vLLM?"
Ответ 2: "vLLM — это высокопроизводительный фреймворк для инференса больших языковых моделей..."

Сообщение 3: "А какие у него преимущества?"
Ответ 3: "Основные преимущества vLLM включают: эффективное управление памятью (PagedAttention)..."
```

**Результат:** ✅ PASS — модель поддерживает контекст диалога (20 последних сообщений).

### Код отправки сообщения

```javascript
async function sendChatMessage() {
    const model = $('chat-model-select')?.value || 'qwen-14b';
    const content = input.value.trim();
    const maxTokens = parseInt($('chat-max-tokens')?.value) || 512;
    const temperature = parseFloat($('chat-temperature')?.value) || 0.7;

    chatHistory.push({ role: 'user', content: content });

    const res = await api('/chat', {
        method: 'POST',
        body: JSON.stringify({
            model: model,
            messages: chatHistory.slice(-20),
            max_tokens: maxTokens,
            temperature: temperature,
        }),
    });
}
```

#### Запрос 2: Техническое продолжение

**Результат:** ✅ PASS — модель корректно работает в режиме completion, а не чата. Это ожидаемое поведение для базовой модели.

## Сравнение моделей

| Характеристика | qwen-14b | qwen-32b-base |
|----------------|----------|---------------|
| Тип | Chat (диалог) | Base (completion) |
| Размер | 14B параметров | 32B параметров |
| Скорость ответа | ~4 сек | ~5 сек |
| Стиль ответа | Диалоговый, дружелюбный | Продолжение текста |
| Многооборотность | ✅ Да | ❌ Нет (completion) |
| Русский язык | ✅ Да | ✅ Да |
| Техническая точность | Хорошая | Отличная (больше параметров) |
| Цвет индикатора | Зелёный (`var(--success)`) | Жёлтый (`var(--warning)`) |

## Обработка ответов (фронтенд)

```javascript
if (res.ok && res.data) {
    let reply = '';
    if (res.data.choices && res.data.choices[0]) {
        const choice = res.data.choices[0];
        reply = choice.message?.content || choice.text || JSON.stringify(choice);
    } else if (res.data.content) {
        reply = res.data.content;
    } else if (res.data.response) {
        reply = res.data.response;
    }

    // Для 32B — может не быть message.content
    if (!reply || reply.trim() === '') {
        reply = res.data.choices?.[0]?.text || 'Пустой ответ от модели.';
    }
}
```

Код корректно обрабатывает оба формата ответа:
- `choices[0].message.content` — для 14B (chat completions)
- `choices[0].text` — для 32B (completion)
