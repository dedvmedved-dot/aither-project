# CB-WEBUI-01 — Готовность системы агентских ключей

## Обзор

CB-WEBUI-01 закладывает фундамент для системы агентских ключей — механизма, позволяющего программным агентам (CLI, SDK, внешние сервисы) аутентифицироваться и использовать API платформы Aither с гранулярными правами доступа.

## Текущее состояние

### Реализовано (CB-WEBUI-01)

| Компонент | Статус | Описание |
|-----------|--------|----------|
| Модель токенов (фронтенд) | ✅ | Структура: id, name, prefix, scopes, created_at, last_used_at, revoked |
| Создание токенов | ✅ | UI форма + `POST /api/v1/tokens` |
| Просмотр токенов | ⚠️ | `GET /api/v1/tokens` (частично — зависит от BFF) |
| Отзыв токенов | ✅ | `DELETE /api/v1/tokens/{id}` с подтверждением |
| Scope-модель | ✅ | `model:14b:chat`, `model:32b:chat-adapter`, `model:32b:completion` |
| Выбор моделей | ✅ | «Обе модели», «Только 14B», «Только 32B» |
| Безопасное отображение | ✅ | Ключ показывается один раз при создании |
| Предупреждение | ✅ | «⚠️ Сохраните ключ сейчас — он больше не будет показан!» |

| Компонент | Приоритет | Описание |

## Архитектура агентской аутентификации

```
Агент (CLI/SDK/Сервис)
    │
    │ Authorization: Bearer {token}
    ▼
VPS2 nginx (:443, :10443)
    │
    ▼
K8s Portal BFF (aither-portal-backend)
    │
    ├── Проверка токена
    │   ├── Поиск в БД по префиксу
    │   ├── Сравнение хеша
    │   ├── Проверка срока действия
    │   └── Проверка не отозван
    │
    ├── Проверка scope
    │   ├── model:14b:chat → доступ к /v1/chat (14B)
    │   ├── model:32b:chat-adapter → доступ к /v1/chat (32B chat)
    │   └── model:32b:completion → доступ к /v1/completions (32B)
    │
    └── Проксирование запроса к AI Platform
```

## Scope-модель

### Определение scope

Scope — это строка формата `resource:target:action`, определяющая право доступа:

```
model:14b:chat          — доступ к чату с qwen-14b
model:32b:chat-adapter  — доступ к чат-адаптеру qwen-32b
model:32b:completion    — доступ к completion для qwen-32b
```

### Матрица прав (UI → Scope)

| Выбор в UI | Scopes |
|------------|--------|
| «Обе модели (14B + 32B)» | `model:14b:chat`, `model:32b:chat-adapter`, `model:32b:completion` |
| «Только qwen-14b (Чат)» | `model:14b:chat` |
| «Только qwen-32b-base (Базовая)» | `model:32b:chat-adapter`, `model:32b:completion` |

### Код маппинга

```javascript
window._createToken = async function() {
    const name = document.getElementById('modal-token-name')?.value?.trim() || 'default';
    const models = document.getElementById('modal-token-models')?.value || 'both';

    let scopes = [];
    if (models === 'both' || models === 'qwen-14b') scopes.push('model:14b:chat');
    if (models === 'both' || models === 'qwen-32b-base') {
        scopes.push('model:32b:chat-adapter', 'model:32b:completion');
    }

    const res = await api('/tokens', {
        method: 'POST',
        body: JSON.stringify({ name, scopes }),
    });
};
```

## Использование ключа агентом

После получения ключа агент может использовать его для API-запросов:

```bash
# Чат через агентский ключ
curl -X POST https://fb1.spb.ru:443/v1/chat/completions \
  -H "Authorization: Bearer tk_live_a1b2c3d4e5f6..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-14b",
    "messages": [{"role": "user", "content": "Привет!"}]
  }'

# Или через BFF
curl -X POST https://fb1.spb.ru:443/api/v1/chat \
  -H "Authorization: Bearer tk_live_a1b2c3d4e5f6..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-14b",
    "messages": [{"role": "user", "content": "Привет!"}]
  }'
```

## План дальнейшего развития

### CB-WEBUI-02 (планируется)

1. **Полноценный BFF CRUD** для `/api/v1/tokens`
   - `POST /api/v1/tokens` — создание (с хешированием)
   - `GET /api/v1/tokens` — список (без полных ключей)
   - `GET /api/v1/tokens/{id}` — детали одного токена
   - `DELETE /api/v1/tokens/{id}` — отзыв
   
2. **Безопасное хранение**
   - Хеширование: `bcrypt(token)` или `scrypt(token)`
   - Хранение префикса (первые 8-12 символов) для идентификации
   - Полный ключ возвращается только при создании

3. **TTL и политики**
   - Настраиваемый срок действия (дни/месяцы/бессрочно)
   - Автоматический отзыв просроченных ключей
   - Политика ротации ключей

### CB-WEBUI-03+ (будущее)

4. **Аудит и мониторинг**
   - `last_used_at` обновляется при каждом использовании
   - Журнал использования токенов (какой endpoint, когда, сколько)
   - Алерты при подозрительной активности

5. **Расширенная scope-модель**
   - Права на админ-операции (`admin:*`)
   - Права на RAG/ChromaDB операции (`rag:query`, `rag:index`)
   - Права на мониторинг (`metrics:read`)

## Заключение

Фундамент системы агентских ключей заложен в CB-WEBUI-01. Фронтенд полностью готов: интерфейс создания/отзыва ключей, scope-модель, безопасное отображение. Для полноценной работы требуется доработка BFF — имплементация CRUD-операций для токенов с безопасным хранением (хеширование) и валидацией.

**Готовность фронтенда:** ✅ 100%
**Готовность бэкенда:** ⚠️ ~60% (ожидается в CB-WEBUI-02)
