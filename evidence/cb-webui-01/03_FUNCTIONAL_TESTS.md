**API вызов:**

## Тест 2: Чат с qwen-14b (русский запрос)

**Шаги:**
1. После входа перейти на страницу «💬 Чат»
2. Выбрать модель `qwen-14b (Чат)` в dropdown
3. Ввести сообщение: «Привет! Как дела?»
4. Нажать Enter

**Ожидаемый результат:** Модель отвечает на русском языке в диалоговом стиле.

**Фактический результат:** ✅ Модель ответила на русском языке. Ответ содержит осмысленный текст в диалоговом формате. Кнопка «📋 Копировать» доступна на сообщении ассистента.

**API вызов:**
```
POST /api/v1/chat
Body: {"model": "qwen-14b", "messages": [{"role": "user", "content": "Привет! Как дела?"}], "max_tokens": 512, "temperature": 0.7}
Response: 200 {"choices": [{"message": {"content": "Здравствуйте! ..."}}]}
```

## Тест 5-6: Автоопределение зоны

**Тест 5 (Интернет):**
- URL: `https://fb1.spb.ru:443/`
- Результат: ✅ Бейдж показывает «INTERNET», класс `.zone-internet`

**Тест 6 (Тестовая зона):**
- URL: `http://10.129.13.78:30080/`
- Результат: ✅ Бейдж показывает «TEST ZONE», класс `.zone-test`

**Логика определения зоны:**
```javascript
function detectZone() {
    const host = window.location.hostname;
    if (host.includes('10.129') || host.includes('test') || host === 'localhost') {
        return 'TEST ZONE';
    }
    return 'INTERNET';
}
```
