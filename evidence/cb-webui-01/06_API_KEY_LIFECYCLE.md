# CB-WEBUI-01 — Жизненный цикл API-ключей

## Текущее состояние

API-ключи управляются через BFF (Backend-for-Frontend) по эндпоинту `/api/v1/tokens`. Система находится в состоянии **частичной готовности**.

## Статус реализации

| Функция | Эндпоинт | Статус | Примечание |
|---------|----------|--------|------------|
| Просмотр списка ключей | `GET /api/v1/tokens` | ⚠️ Частично | Может не загружаться при проблемах с BFF |
| Создание ключа | `POST /api/v1/tokens` | ✅ Реализован | Поддерживает выбор моделей и scopes |
| Отзыв ключа | `DELETE /api/v1/tokens/{id}` | ✅ Реализован | С подтверждением через `confirm()` |
| Валидация ключа | Через BFF middleware | ✅ Реализован | BFF проверяет токен при запросах |

## Модель данных токена

```json
{
    "id": "tk_abc123...",
    "name": "Разработка",
    "prefix": "tk_abc...",
    "scopes": ["model:14b:chat", "model:32b:chat-adapter", "model:32b:completion"],
    "created_at": "2026-07-25T10:00:00Z",
    "last_used_at": null,
    "revoked": false
}
```

## Scope-модель (грани прав доступа)

| Scope | Модель | Тип доступа |
|-------|--------|-------------|
| `model:14b:chat` | qwen-14b | Чат (диалоговый режим) |
| `model:32b:chat-adapter` | qwen-32b-base | Чат-адаптер (диалоговый) |
| `model:32b:completion` | qwen-32b-base | Completion (продолжение текста) |

## Интерфейс создания ключа

### Поля формы:

| Поле | Тип | Описание |
|------|-----|----------|
| Название ключа | `text` | Произвольное имя (например, «Разработка») |
| Модели | `select` | «Обе модели», «Только qwen-14b», «Только qwen-32b-base» |

### Логика выбора scope:

```javascript
let scopes = [];
if (models === 'both' || models === 'qwen-14b') {
    scopes.push('model:14b:chat');
}
if (models === 'both' || models === 'qwen-32b-base') {
    scopes.push('model:32b:chat-adapter', 'model:32b:completion');
}
```

### Процесс создания:

1. Пользователь заполняет форму и нажимает «Создать»
2. Отправляется `POST /api/v1/tokens` с `{name, scopes}`
3. BFF генерирует токен и возвращает его **один раз**
4. Интерфейс показывает ключ с предупреждением: «⚠️ Сохраните ключ сейчас — он больше не будет показан!»
5. Ключ можно скопировать кнопкой «Копировать»

## Отзыв ключа

1. На странице «🔑 API Ключи» отображается таблица ключей
2. Для каждого активного ключа доступна кнопка «Отозвать»
3. При нажатии — диалог подтверждения: «Отозвать этот ключ? Это действие нельзя отменить.»
4. После подтверждения — `DELETE /api/v1/tokens/{id}`
5. Список ключей обновляется

## Известные проблемы

### Страница API-ключей не загружается

**Симптом:** При переходе на страницу «🔑 API Ключи» отображается «Не удалось загрузить ключи.»

**Вероятная причина:** BFF не реализует endpoint `/api/v1/tokens` полностью или возвращает ошибку.

**Обходной путь:** Прямое использование API через curl:

```bash
# Создание ключа
curl -X POST https://fb1.spb.ru:443/api/v1/tokens \
  -H "Content-Type: application/json" \
  -H "Cookie: session=..." \
  -d '{"name": "test", "scopes": ["model:14b:chat"]}'

# Просмотр ключей
curl https://fb1.spb.ru:443/api/v1/tokens \
  -H "Cookie: session=..."

# Отзыв ключа
curl -X DELETE https://fb1.spb.ru:443/api/v1/tokens/{id} \
  -H "Cookie: session=..."
```
