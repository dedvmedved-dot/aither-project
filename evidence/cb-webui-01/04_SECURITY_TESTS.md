## Тест 1: Вход с валидными учётными данными

**Шаги:**
1. Открыть `https://fb1.spb.ru:443/`
2. Ввести `admin` / `***`
3. Нажать «Войти»

**Результат:** ✅
- HTTP 200 OK
- BFF устанавливает сессионную cookie
- `localStorage` сохраняет `aither_token`
- Навигационная панель отображается
- Переход на «Панель управления»

**Запрос:**
```
POST /api/v1/auth/login
Content-Type: application/json
Body: {"username": "admin", "password": "***"}
```

**Ответ:**
```json
{
    "status": "ok",
    "session_id": "sess_abc123...",
    "user": {
        "username": "admin",
        "role": "administrator"
    }
}
```

## Тест 5: Выход из сессии

**Шаги:**
1. Выполнить вход
2. Нажать «Выход» в навигационной панели

**Результат:** ✅
- Вызов `POST /api/v1/auth/logout`
- `authToken` установлен в `null`
- `currentUser` установлен в `null`
- `chatHistory` очищен
- `localStorage.removeItem('aither_token')`
- Навигационная панель скрыта
- Страница входа показана

**Код выхода:**
```javascript
async function handleLogout() {
    setLoading(true);
    try { await api('/auth/logout', { method: 'POST' }); } catch {}
    authToken = null; currentUser = null; chatHistory = [];
    localStorage.removeItem('aither_token');
    updateNav(); showPage('login');
    setLoading(false);
}
```

## Тест 10: CSRF-защита

**Результат:** ✅
- Все fetch-запросы используют `credentials: 'same-origin'`
- Это предотвращает отправку cookie на кросс-доменные запросы

```javascript
async function api(path, opts = {}) {
    const headers = { 'Content-Type': 'application/json', ...opts.headers };
    if (authToken && !path.startsWith('/auth/')) {
        headers['Authorization'] = 'Bearer ' + authToken;
    }
    try {
        const res = await fetch(API_URL + path, { ...opts, headers, credentials: 'same-origin' });
        // ...
    }
}
```
