# CB-WEBUI-01 — Результаты двухзонального тестирования

## Обзор

CB-WEBUI-01 предусматривает доступ к Web UI платформы Aither в двух независимых зонах:
- **Интернет-зона** — публичный доступ через HTTPS на домене `fb1.spb.ru`
- **Тестовая зона** — внутренний доступ через прямое подключение к K8s NodePort

## Зона 1: Интернет (`https://fb1.spb.ru:443`)

### Конфигурация

| Параметр | Значение |
|----------|----------|
| URL | `https://fb1.spb.ru:443/` |
| Протокол | HTTPS (SSL/TLS) |
| Обратный прокси | VPS2 nginx (`/root/nginx-failover.conf`) |
| Бэкенд | K8s NodePort `10.129.13.78:30080` |
| Сертификат | `/etc/nginx/ssl/cert.pem`, `/etc/nginx/ssl/key.pem` |

### Результаты тестирования

| Тест | Ожидаемый результат | Фактический результат | Статус |
|------|---------------------|-----------------------|--------|
| Доступность Web UI | HTTP 200, загрузка страницы входа | Страница входа загружена | ✅ PASS |
| HTTPS-соединение | Валидный SSL-сертификат | SSL handshake успешен | ✅ PASS |
| Аутентификация | Успешный вход через BFF | Вход выполнен | ✅ PASS |
| Чат 14B через Интернет | Ответ от qwen-14b | Ответ получен | ✅ PASS |
| Чат 32B через Интернет | Ответ от qwen-32b-base | Ответ получен | ✅ PASS |
| API через Интернет | `/api/v1/*` доступны | Эндпоинты отвечают | ✅ PASS |
| Выделенный порт 32B | `:10443` работает | Порт 10443 доступен | ✅ PASS |
| Определение зоны | Бейдж «INTERNET» | Отображается «INTERNET» | ✅ PASS |

### Автоопределение зоны

Хостнейм `fb1.spb.ru` не содержит признаков тестовой зоны (`10.129`, `test`, `localhost`), поэтому:

```javascript
detectZone() → 'INTERNET'
ZONE_CLASS → 'zone-internet'
```

Бейдж в навигационной панели: **INTERNET** (стиль `zone-internet`).

## Сравнение зон

| Характеристика | Интернет | Тестовая |

| Доступ | Публичный (Интернет) | Внутренний (10.129.13.0/24) |
