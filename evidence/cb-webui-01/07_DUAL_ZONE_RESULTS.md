# CB-WEBUI-01 — Результаты двухзонального тестирования

## Обзор

CB-WEBUI-01 предусматривает доступ к Web UI платформы Aither в двух независимых зонах:

**Статус:** ✅ **CLOSED (Remediated)** — 2026-07-25

**Влияние на двухзональное тестирование:**

## Безопасность token_id в двухзональном контексте

`token_id` (12 hex-символов) — безопасный идентификатор, не пригодный для аутентификации. Его видимость не зависит от зоны доступа:

| Контекст | Интернет-зона | Тестовая зона |
|----------|---------------|---------------|
| Передача в URL (`/api/v1/tokens/{token_id}`) | Через HTTPS (зашифровано) | Через HTTP (внутренняя сеть) |
| Отображение в UI (префикс) | Видим в браузере | Видим в браузере |
| Использование как Bearer-токен | ❌ НИКОГДА | ❌ НИКОГДА |
| Участие в аутентификации | ❌ НЕТ | ❌ НЕТ |

**Вывод:** `token_id` безопасен в обеих зонах — это всегда только идентификатор БД, не секрет.
