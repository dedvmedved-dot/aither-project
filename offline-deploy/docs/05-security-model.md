# 05-security-model.md — Модель угроз и меры защиты

## Уровни защиты

| Уровень | Механизм | Компонент |
|---|---|---|
| Периметр | UFW (22, 80, 443) | VPS |
| Транспорт | HTTPS (в планах) | Nginx |
| Аутентификация | OAuth / JWT / API-ключи | BFF |
| Авторизация | JWT RS256 делегирование | Gateway |
| Инъекции | Prompt Injection (29 паттернов) | Gateway |
| Утечки | DLP (8 типов данных) | Gateway |
| Нагрузка | Rate Limiter (60 RPM / 100K TPM) | Gateway + Redis |
| Доступ | RBAC (ClusterRole) | K8s |
| Сеть | NetworkPolicy (в планах) | K8s |
