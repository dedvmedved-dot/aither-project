# 04-user-guide.md — Руководство пользователя

> Полное руководство: `docs/user-guide.md` в основном репозитории.

## Быстрый старт

1. Откройте http://YOUR_PORTAL_IP в браузере
2. Войдите через OAuth (Google/GitHub/Яндекс)
3. Выберите организацию → «Новый чат»
4. Выберите модель и начните диалог

## API

```bash
# Получить список моделей
curl http://YOUR_PORTAL_IP/api/v1/models

# Отправить запрос
curl -X POST http://YOUR_PORTAL_IP/api/v1/chat/completions \
  -H "Authorization: Bearer ***  -H "Content-Type: application/json" \
  -d '{"model":"qwen2.5-14b","messages":[{"role":"user","content":"Привет!"}]}'
```

## API-ключи

1. Портал → организация → «API-ключи»
2. «Создать ключ» → скопировать (показывается один раз)

## Ограничения

- 60 запросов/мин на организацию
- 100 000 токенов/мин на организацию
- Стартовый баланс: 100 000 токенов
- Авто-пополнение: до 10 раз

## Модели

| Модель | Для чего | max_tokens |
|---|---|---|
| Qwen 2.5 14B | Код, быстрые ответы | 4096 |
| Qwen 2.5 32B | Анализ, сложные задачи | 8192 |
